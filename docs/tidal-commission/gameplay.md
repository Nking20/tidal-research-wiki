# 基础玩法

## 打开委托板

1.5.0 默认不要求玩家携带委托板。玩家可以通过以下入口打开委托界面：

- 物品栏右下方的潮汐委托底部页签。
- 默认快捷键 `R`。
- 玩家命令 `/tc open`。
- 右键使用潮汐委托板。
- 其他兼容模组调用潮汐委托的打开接口。

服务器可以分别关闭物品栏按钮、快捷键和玩家命令，也可以把访问模式改为必须持有委托板、持有一次后永久解锁，或仅允许外部接口打开。Curios 中的委托板仍可用于需要物品的访问模式。

## 委托流程

1. 打开潮汐委托板。
2. 选择一个灰色栏位。
3. 选择档位并翻开委托卡。
4. 查看委托内容。
5. 选择接受或放弃。
6. 接受后完成一个或多个任务目标。
7. 需要手动交付时，在详情界面提交；击杀和探索目标会自动推进。
8. 达成组合规则后提交委托。
9. 若存在可选奖励，先选择方案；结算后栏位进入冷却。

## 目标与交付

内置目标包括：

| 类型 | 推进方式 |
| --- | --- |
| 物品 | 提交指定物品，可按组件数据进一步区分。 |
| 物品标签 | 提交标签内的任意有效物品。 |
| 击杀实体 | 玩家击杀匹配实体时自动累计。 |
| 到达群系 | 玩家进入匹配群系时自动完成。 |

物品和标签目标可使用三种交付方式：

- **提交并消耗**：一次提交足够数量后消耗。
- **只检查**：只检查玩家是否持有，不消耗物品。
- **分批存入**：允许多次提交，累计达到数量后完成。

多个目标可以要求全部完成、任意一项完成，或至少完成指定数量。每项目标的进度相互独立。

## 奖励方式

- **固定奖励**：完成后直接发放，可包含多项物品、经验或命令奖励。
- **可选奖励**：从多个方案中选择指定数量，每个方案也可以包含多项奖励。
- **混合奖励**：先发固定奖励，再让玩家选择额外方案。

固定奖励不是必填项，因此可以制作只有可选奖励的委托。

## 栏位状态

| 状态 | 说明 |
| --- | --- |
| 灰卡 | 未翻开，可以选择档位和来源 |
| 白卡 | 已翻开，可以接受或放弃 |
| 进行中 | 已接受，显示剩余时间，并可进入详情页 |
| 惩罚 | 放弃或超时后进入等待 |
| 冷却 | 完成委托后进入等待 |

## 指定来源栏位

服务器可以把某些栏位设置为指定来源栏位。指定来源栏位允许玩家选择来源，再选择档位并翻开任务。

这个功能适合让玩家更稳定地获取某一类委托，例如只想接官方委托、灰色组织委托，或整合包作者新增的工厂类来源。

## 调度令

调度令用于刷新当前委托板里剩余时间最长的惩罚或冷却栏位。

规则：

- 需要玩家身上有潮汐委托板。
- 默认有使用冷却。
- 成功使用后，目标栏位会重新变成可翻开的灰卡。
- 没有可刷新的栏位时不会消耗。

## 担保凭证

担保凭证用于接取普通委托时抵扣接取成本。

规则：

- 接受普通委托时优先使用。
- 只抵扣接取成本。
- 不抵扣翻牌成本。
- 不抵扣提交任务所需物品。
