# 基础玩法

## 打开委托板

玩家持有潮汐委托板后，可以右键打开委托界面。

默认快捷键为 `R`。当背包或 Curios 栏位中存在潮汐委托板时，按 `R` 可以打开界面；界面已经打开时，再按 `R` 可以关闭。

## 委托流程

1. 打开潮汐委托板。
2. 选择一个灰色栏位。
3. 选择档位并翻开委托卡。
4. 查看委托内容。
5. 选择接受或放弃。
6. 接受后，准备任务所需物品。
7. 在详情界面提交物品。
8. 完成后获得奖励，对应栏位进入冷却。

## 栏位状态

| 状态 | 说明 |
| --- | --- |
| 灰卡 | 未翻开，可以选择档位和来源 |
| 白卡 | 已翻开，可以接受或放弃 |
| 进行中 | 已接受，显示剩余时间，并可进入详情页 |
| 惩罚 | 放弃或超时后进入等待 |
| 冷却 | 完成委托后进入等待 |

## 指定来源栏位

服务器可以把某些栏位设置为指定来源栏位。指定来源栏位允许玩家选择来源，再选择档位并翻开任务。

这个功能适合让玩家更稳定地获取某一类委托，例如只想接官方委托、灰色组织委托，或整合包作者新增的工厂类来源。

## 调度令

调度令用于刷新当前委托板里剩余时间最长的惩罚或冷却栏位。

规则：

- 需要玩家身上有潮汐委托板。
- 默认有使用冷却。
- 成功使用后，目标栏位会重新变成可翻开的灰卡。
- 没有可刷新的栏位时不会消耗。

## 担保凭证

担保凭证用于接取普通委托时抵扣接取成本。

规则：

- 接受普通委托时优先使用。
- 只抵扣接取成本。
- 不抵扣翻牌成本。
- 不抵扣提交任务所需物品。
