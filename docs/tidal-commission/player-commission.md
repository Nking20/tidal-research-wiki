# 玩家自定义委托

玩家自定义委托允许玩家发布任务，让其他玩家接取并完成。该功能适合服务器使用，也可以在配置中关闭。

## 发布规则

- 玩家只能从当前配置启用的来源中选择来源。
- 当前需求类型以物品为主。
- 奖励由发布者放入奖励槽位。
- 发布者不能接取并完成自己的委托。
- 委托过期后，未发出的奖励会退回。

## 接取规则

- 自定义委托会进入对应来源的任务池。
- 发布时可以设置最多接取人数。
- 达到接取人数上限后，其他玩家不能再接取该委托。
- 如果某个玩家完成了该委托，其他已接取同一委托的玩家会失效并进入完成冷却。
- 完成时可以全服广播，具体由配置决定。

## 管理任务

发布者可以在委托界面进入管理页，查看自己发布中的玩家委托，并取消未完成的委托。

## 服务器建议

- 默认关闭或降低玩家自定义委托权重，避免盖过数据包任务。
- 对奖励槽数量、可接取人数和单个需求数量设置上限。
- 定期查看配置文件和日志，避免玩家提交不可用物品 ID。
