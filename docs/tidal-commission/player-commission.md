# 玩家自定义委托

玩家自定义委托允许玩家发布任务，让其他玩家接取并完成。

这个功能主要面向服务器。它适合让玩家用自己的奖励换取其他玩家提供的物品。

## 发布规则

- 玩家只能从当前配置中已启用的来源里选择。
- 需求目前只支持物品。
- 奖励来自发布者背包中的真实物品。
- 发布成功后，奖励会从发布者背包中扣除并保存到世界数据。
- 发布者不能完成自己发布的委托。
- 委托过期后，奖励会退回发布者。

## 接取规则

- 玩家委托会进入任务池，并按配置权重参与抽取。
- 可以设置单个委托最多允许多少人接取。
- 当接取人数达到上限后，其他玩家不能继续接取该委托。
- 当有人完成该委托时，奖励发给完成者。
- 其他已经接取同一委托的玩家，对应栏位会失效并进入完成冷却。

## 管理任务

玩家可以在管理界面查看自己发布中的委托。

当前管理用途：

- 查看已经发布的玩家委托。
- 在无人接取时取消委托。
- 取消后返还已存入的奖励。

## 服务器建议

- 玩家委托默认不应该比数据包任务出现得过高。
- 高价值奖励建议配合服务器规则或经济系统控制。
- 如果服务器允许玩家大量发布委托，应限制单人发布上限和委托过期时间。
