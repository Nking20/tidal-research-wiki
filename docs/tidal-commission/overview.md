# 潮汐委托

潮汐委托是一个面向整合包作者的服务端权威委托系统：玩家翻开并接取委托，在限时内完成交付、清剿、探索等目标，再领取固定或可选奖励。任务来源、目标、权重、冷却、阶段条件与玩家委托均由服务端决定。

## 1.5.0 开发重点

- **不再强制依赖物品**：默认可以从物品栏底部页签、快捷键或 `/tc open` 直接进入委托界面，也可改回必须持有委托板。
- **复合任务目标**：一项委托可同时包含物品、标签、击杀实体和到达群系目标，并选择全部、任意或至少完成若干项。
- **精确物品匹配**：支持按组件数据区分同一物品 ID 下的不同药水、酒类或其他模组物品。
- **更灵活的奖励**：固定奖励不再是必选项，可创建纯固定、纯可选或混合奖励委托。
- **任务链与重复限制**：可设置前置委托、仅一次、冷却、每日或每周完成规则。
- **游戏内配置管理**：任务及来源大类都可通过可视化编辑器管理，保存后由服务端重新加载。

当前版本仍在测试中，详见 [1.5.0 当前开发状态](./status.md)。

## 主要内容

- 五个独立状态的委托栏位，以及可选的指定来源栏位。
- 官方、民间、灰色组织等可配置来源；整合包也可新增来源。
- 数据驱动任务、可视化任务编辑器和来源分类编辑器。
- 多目标组合、分批交付、组件匹配、可选奖励、重复规则和前置任务。
- 调度令、担保凭证与委托总集。
- 可选的玩家自定义委托与 Curios 联动。
- 静态任务支持数据包初始化、配置文件维护，以及 KubeJS 阶段驱动。

## 服务端规则

联机环境以服务端 `config/tidalcommission/` 和服务端数据包为准。客户端本地配置不决定任务抽取、来源权重、阶段、冷却或玩家委托。

修改任务后，推荐执行：

```text
/tc reload
/tc doctor
```
