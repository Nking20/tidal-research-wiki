# 潮汐委托

潮汐委托是一个服务端权威的委托板模组：翻开任务、支付接取成本、在限时内交付物品，并领取奖励。任务来源、权重、冷却、阶段条件与玩家委托都由服务端决定。

## 1.4.0 新增内容

- **阶段委托**：静态任务可按玩家阶段决定是否出现，并可修正抽取权重。
- **诊断命令**：`/tc doctor` 与 `/tc doctor <玩家>` 可检查任务池和玩家实际可抽到的任务。
- **更可靠的任务加载**：内置与数据包任务使用 `tidal_commission_tasks` 目录；运行时任务统一从服务端配置目录读取。
- **稳定性修复**：委托板与新手引导状态会在死亡重生后保留；新手提示不再反复显示。

## 主要内容

- 五个独立状态的委托栏位。
- 官方、民间、灰色组织等可配置来源；整合包也可新增来源。
- 调度令、担保凭证与委托总集。
- 可选的玩家自定义委托与 Curios 联动。
- 静态任务支持数据包初始化、配置文件维护，以及 KubeJS 阶段驱动。

## 服务端规则

联机环境以服务端 `config/tidalcommission/` 和服务端数据包为准。客户端本地配置不决定任务抽取、来源权重、阶段、冷却或玩家委托。

修改任务后，推荐执行：

```text
/tc reload
/tc doctor
```
