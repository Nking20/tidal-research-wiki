# 潮汐委托

潮汐委托是一个任务型模组。玩家通过潮汐委托板翻开委托卡，支付接取成本，提交指定物品并获得奖励。

模组的核心内容可以由服务器或整合包作者调整，包括委托来源、来源权重、任务内容、任务奖励、冷却时间、玩家自定义委托规则等。

## 主要内容

- 五个委托栏位。
- 三个任务档位。
- 默认来源：官方、民间、灰色组织。
- 支持新增来源，也可以把默认来源权重调为 0。
- 支持数据包和 KubeJS 添加或替换任务。
- 支持玩家发布自定义委托。
- 支持服务端配置同步。
- Curios 为可选联动；没有 Curios 时不影响基础功能。

## 主要物品

| 物品 | 注册名 | 用途 |
| --- | --- | --- |
| 潮汐委托板 | `tidalcommission:commission_board` | 打开委托界面 |
| 调度令 | `tidalcommission:dispatch_token` | 刷新当前剩余时间最长的惩罚或冷却栏位 |
| 担保凭证 | `tidalcommission:guarantee_voucher` | 接取普通委托时优先抵扣接取成本 |

调度令和担保凭证默认适合交给整合包作者或服务器自行设计获取方式。

## 服务端规则

潮汐委托的任务池、来源权重、时间规则和玩家委托规则都应以服务端为准。

在服务器中使用时，建议：

- 服务端安装模组。
- 客户端安装同版本模组。
- 所有配置以服务端 `config/tidalcommission/` 为准。
- 任务 JSON 通过数据包或 KubeJS 放在服务端。

## 可选联动

Curios 不是必需前置。

安装 Curios 时，潮汐委托板可以放入对应饰品栏，并可通过快捷键打开委托界面。没有 Curios 时，玩家仍然可以通过背包内的潮汐委托板使用基础功能。
