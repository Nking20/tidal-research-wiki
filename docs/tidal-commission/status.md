# 1.6.0 当前状态

潮汐委托 1.6.0 已完成当前计划内容，并通过 NeoForge 1.21.1 客户端启动、Gradle 自动测试和正式构建验证。

## 已经实现

- **自动补充与等待接取期限**：可配置补充间隔、数量、接取时限和过期栏位冷却。
- **接取后无期限任务**：任务 `duration` 为 `0` 时不会产生完成期限，并包含默认示例任务。
- **委托追踪 HUD**：最多追踪三份任务，支持位置、缩放、透明度、边距、折叠和目标行数设置。
- **任务日志**：记录最多 200 条成功、失败或放弃记录，并可按结果筛选。
- **完成与送达提示**：自动目标达成和自动补充委托均可显示带简介的右上角提示。
- **游戏内配置中心**：`/tc config` 集中管理客户端显示以及刷新、时限、费用、入口和玩家委托规则。
- **玩家委托界面重做**：加入三步发布流程、多行说明、输入提示、背包选择、数量调整和发布预览。
- **档案界面重做**：任务日志和完成总集共用新的双页布局。
- **Curios 联动移除**：不再包含 Curios 依赖、槽位或委托板检测。

## 已完成的修复与验证

- 修复死亡后完成总集累计进度丢失。
- 修复玩家委托需求数量无法修改，以及输入简介或详情时按键退出界面的问题。
- 修复物品标签与群系标签在数据加载早期可能被错误拒绝的问题。
- 自动补充计划、等待接取期限和任务日志均会持久保存。
- 当前代码已通过 Gradle 测试、正式构建和 NeoForge 1.21.1 客户端启动检查。

## 建议持续回归的内容

- 多人服务器中的自动补充、等待接取过期和任务日志同步。
- 长时间存档中的无期限任务、每日/每周限制和完成冷却。
- 不同 GUI 缩放、分辨率与其他 HUD 模组同时使用时的追踪栏位置。
- 从 1.5.0 存档升级后的委托板、完成总集与玩家委托数据。

1.6.0 当前可以作为正式版本发布；后续问题将按补丁版本继续维护。
