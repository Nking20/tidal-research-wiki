# 常见问题

## 权重总和必须等于 100 吗？

不需要。权重按“单项权重 / 总权重”计算。

## 为什么我新增来源后抽不到任务？

检查：

- `commission_rules.json` 中来源是否 `enabled=true`。
- 来源 `weight` 是否大于 0。
- 任务 JSON 的 `source` 是否与来源 ID 一致。
- 任务档位是否与玩家选择的档位一致。
- 任务需求、接取成本、奖励物品 ID 是否存在。
- 如果是数据包/KubeJS，是否执行 `/reload` 或重启。

## 为什么某些 Farmer's Delight 任务没出现？

如果没有安装 Farmer's Delight，引用 `farmersdelight:*` 物品的任务会被跳过。

## 灰色任务为什么看不到奖励？

灰色组织任务设计上显示“未知”。完成后从 `gray_reward_pools.json` 对应档位随机发奖。

## 自定义委托为什么自己不能完成？

当前设计禁止发布者完成自己的自定义委托，避免玩家把自定义委托当成免费储物或刷奖励系统。

## 自定义委托过期后奖励去哪？

过期后奖励退回发布者。如果发布者不在线，会在之后登录时处理退回。

## 别人完成了我也接了的自定义委托怎么办？

如果某个玩家完成了同一个自定义委托，其他已接取该委托的玩家对应栏位会进入完成冷却。

## 可以让多个玩家接同一个自定义委托吗？

可以。发布时有可接取人数设置，最大值由 `max_accepts_limit` 控制。

## 玩家自定义委托是否容易被抽到？

由 `player_commission_pick_weight` 控制。值越高，玩家委托相对普通委托越容易出现。

## Curios 是必需的吗？

不是。Curios 是可选联动。没有 Curios 时，潮汐委托板仍可放在背包中使用。
