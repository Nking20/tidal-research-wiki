# 潮汐观测卡

潮汐观测卡是潮汐研究社系列中的卡牌型奖励与兑换模组。玩家通过观测卡翻开每日或周期刷新的卡牌，先支付观测成本查看奖励，再决定兑换或放弃；这些操作会积累潮汐值，用于进入独立的潮汐轮转玩法。

模组适合服务器和整合包作者用于设计可配置的奖励池、货币体系和阶段性抽取玩法。

## 主要内容

- 观测卡界面默认每页 12 张卡，支持多页。
- 支持手动选择观测等级、随机单等级模式和隐藏等级模式。
- 每个等级可以配置独立观测货币、观测成本、兑换货币和兑换价格。
- 奖励池支持物品、经验、效果、货币、潮汐值和观测增益。
- 支持观测动画、翻牌动画和整页观测。
- 观测、兑换和放弃会按奖励等级积累持久化潮汐值。
- 潮汐轮转分为浅潮、回潮和深潮三种模式。
- 支持观测代券和兑换代券；旧轮转代券可转换为一份浅潮所需的潮汐值。
- 提供游戏内奖励池可视化编辑器。
- 提供兑换、放弃和轮转的最近记录。
- JEI 和模组列表中的模组显示名为 `潮汐观测卡`。
- 支持服务端配置同步。
- 支持 VSS、FTB Library 虚拟货币，并开放第三方货币 Provider API。

## 主要物品

| 物品 | 注册名 | 用途 |
| --- | --- | --- |
| 潮汐观测卡 | `trs:tidal_observation_card` | 打开观测卡界面 |
| 观测代券 | `trs:observe_voucher_1` 到 `trs:observe_voucher_5` | 优先抵扣对应等级的观测成本 |
| 兑换代券 | `trs:redeem_voucher_1` 到 `trs:redeem_voucher_5` | 优先抵扣对应等级的兑换成本 |
| 轮转代券 | `trs:spin_voucher` | 旧版兼容物品；右键转换为一份浅潮所需的潮汐值 |

## 服务端规则

服务器环境中，实际玩法以服务端配置为准。客户端进入服务器后会同步服务端的观测等级、奖励池、界面规则和轮转配置。虚拟货币的余额读取与扣除同样由服务端执行。

建议服务器管理员只维护服务端：

```text
config/trs/
```

客户端本地配置可以不同，但不应该作为服务器玩法判断依据。

客户端和服务端必须使用相同版本。

## 虚拟货币兼容

需要使用 VSS、FTB Library 或其他模组货币时，请查看[虚拟货币与兼容 API](./currency-api.md)。普通玩家和整合包作者只需要修改 `tidal_levels.json5`；第三方模组开发者可以注册自己的 CurrencyProvider。
