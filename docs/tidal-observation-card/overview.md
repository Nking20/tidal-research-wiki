# 潮汐观测卡

潮汐观测卡是潮汐研究社系列中的卡牌型奖励与兑换模组。玩家通过观测卡翻开每日或周期刷新的卡牌，先支付观测成本查看奖励，再决定兑换、放弃或进入潮汐轮转。

模组适合服务器和整合包作者用于设计可配置的奖励池、货币体系和阶段性抽取玩法。

## 主要内容

- 观测卡界面默认每页 12 张卡，支持多页。
- 支持手动选择观测等级、随机单等级模式和隐藏等级模式。
- 每个等级可以配置独立观测货币、观测成本、兑换货币和兑换价格。
- 奖励池支持物品、标签、权重、数量范围和兑换价格范围。
- 支持观测动画、翻牌动画和整页观测。
- 已观测奖励可选择兑换、放弃，或进入潮汐轮转。
- 支持观测代券、兑换代券和轮转代券。
- JEI 和模组列表中的模组显示名使用英文 `Tidal Observation Card`。
- 支持服务端配置同步。
- 支持 Curios 可选联动；没有 Curios 时不影响基础功能。

## 主要物品

| 物品 | 注册名 | 用途 |
| --- | --- | --- |
| 潮汐观测卡 | `trs:tidal_observation_card` | 打开观测卡界面 |
| 观测代券 | `trs:observe_voucher_1` 到 `trs:observe_voucher_5` | 优先抵扣对应等级的观测成本 |
| 兑换代券 | `trs:redeem_voucher_1` 到 `trs:redeem_voucher_5` | 优先抵扣对应等级的兑换成本 |
| 轮转代券 | `trs:spin_voucher` | 优先抵扣潮汐轮转入场成本 |

## 服务端规则

服务器环境中，实际玩法以服务端配置为准。客户端进入服务器后会同步服务端的观测等级、奖励池、界面规则和轮转配置。

建议服务器管理员只维护服务端：

```text
config/trs/
```

客户端本地配置可以不同，但不应该作为服务器玩法判断依据。

## 可选联动

Curios 不是必需前置。

安装 Curios 时，潮汐观测卡可以放入对应饰品栏，并可通过快捷键打开界面。没有 Curios 时，玩家仍然可以通过背包中的潮汐观测卡打开界面。
