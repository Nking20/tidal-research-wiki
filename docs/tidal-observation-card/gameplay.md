# 潮汐观测卡基础玩法

潮汐观测卡的核心流程是：选择、随机获得或隐藏获得观测等级，支付观测成本翻开卡牌，再决定兑换或放弃奖励。观测、兑换和放弃都会积累潮汐值，潮汐值可以用于独立的潮汐轮转；钓鱼时还可能进入漂流瓶与河神奇遇。

## 卡牌状态

| 状态 | 说明 |
| --- | --- |
| 未观测 | 尚未支付观测成本，卡面显示可选等级或随机等级 |
| 已观测 | 已翻开奖励，可以兑换或放弃 |
| 已兑换 | 已支付兑换成本并领取奖励 |
| 已放弃 | 放弃奖励并领取放弃补偿 |
| 已轮转 | 旧版轮转卡牌状态，仅用于兼容旧数据 |

## 观测流程

1. 打开潮汐观测卡界面。
2. 在未观测卡上选择等级，或在随机单等级模式下确认随机出的等级。
3. 支付对应等级的观测成本。
4. 观测动画结束后，卡牌翻开并显示奖励。

隐藏等级模式下，灰卡不会提前显示真实等级。玩家按配置中的默认成本档位支付观测成本，翻开后才显示本次实际等级和奖励。

如果背包中有对应等级的观测代券，会优先消耗代券；没有代券时才消耗配置中的观测货币。

## 兑换与放弃

已观测卡可以继续处理：

| 操作 | 说明 |
| --- | --- |
| 兑换 | 支付卡面显示的兑换成本，获得奖励物品 |
| 放弃 | 不领取原奖励，改为领取对应等级的放弃补偿 |

兑换时如果背包中有对应等级的兑换代券，会优先消耗代券。

## 潮汐值

观测、兑换和放弃都会根据卡牌等级增加潮汐值。默认情况下，高等级操作获得的潮汐值更多。

潮汐值分为三段：

- I～II 级操作最多积累到第一段上限。
- III～IV 级操作最多积累到第二段上限。
- V 级操作可以积累到完整上限。

因此只处理低等级卡牌可以反复进入浅潮，但无法单靠低等级操作解锁回潮和深潮。潮汐值会随玩家数据保存。

## 观测全部

`观测全部` 只作用于当前页未观测的卡牌。

在手动等级模式下，按钮会使用当前选择的等级。  
在随机单等级模式下，每张卡会使用自己随机到的等级。
在隐藏等级模式下，每张卡会在服务器确认观测时独立随机实际等级。

如果成本不足，不会部分扣费后继续强行翻开。服务器会先计算代券与货币是否足够，再执行整页观测。

## 潮汐轮转

潮汐轮转是消耗潮汐值进入的独立符号玩法，不再直接消耗某张已观测卡。

| 模式 | 默认消耗 | 特点 |
| --- | ---: | --- |
| 浅潮 | 100 | 符号较少，操作空间较大，奖励等级较低 |
| 回潮 | 400 | 中等符号数量与奖励范围，需要进入第二段潮汐值 |
| 深潮 | 1000 | 符号最多，可获得更高等级奖励，需要进入第三段潮汐值 |

轮转中可以：

- 锁定符号位置。
- 使用圆环上的微调选项刷新或改变符号。
- 根据最终牌型结算奖励。
- 查看月相对本轮的影响。

轮转模式消耗、潮汐值获取、起始操作点、奖励等级、微调成本和月相效果由 `tidal_spin.json5` 控制。

旧版轮转代券不再作为正常奖励产出。玩家已持有的旧代券可以右键转换为一份浅潮所需的潮汐值。

## 漂流瓶与河神

真正钓到物品时，玩家可能自然遇见河神；没有触发河神时，本次渔获也可能被替换为漂流瓶。

漂流瓶使用流程：

1. 右键漂流瓶，阅读物品栏上方显示的一句瓶中预示。
2. 漂流瓶被消耗，并返还一个玻璃瓶。
3. 下一次真正钓到物品时必定遇见河神。
4. 如果已经激活过漂流瓶，再次使用不会重复消耗。

河神出现后会提出一组问题，并显示四个选择：

- 固定的“只取回原物”是安全选项，会直接返还原渔获。
- 另外三个回答从对应问题的回答池中随机出现。
- 河神满意时会返还原物，并在幸运、额外渔获或河神赠礼中抽取一种结果。
- 河神不满意时会在霉运或没收中抽取一种结果；没收会从独立失败池返还一份物品。

具体概率、效果时间和奖励池由 `river_god.json5` 控制。

## 刷新周期

观测卡可以按配置刷新。刷新后未结算或已打开的卡牌会回到新周期状态。

如果玩家当前周期一张卡都没有打开，刷新不会额外弹出提示，也不需要关闭界面。
