# 更新日志

## 辑录与揭秘 1.2.0

- 物品栏底部新增辑录册入口；点击打开辑录册，Shift 点击进入揭秘界面。
- 辑录册新增揭秘、共享和研究日志入口，并加入未读五角星标记。
- 支持把全部进度导出为共享辑录页，其他玩家使用后可收录自己尚未拥有的内容。
- 解锁条件新增击杀生物、进入群系和完成进度。
- 解锁方式可以作用于整个篇章或指定辑录，并可设置材料是否消耗及提示显示位置。
- 可视化编辑器加入物品、生物、群系和进度选择器，移除“手持填入”。
- 新增“杂项”篇章与指南针、时钟、命名牌三条独立辑录。
- JEI 会标明材料是否保留；辑录册中的 Tag 材料提示改为可读名称或示例物品。

## 潮汐培育 0.1.0-alpha

- 加入七类海洋样本的采样、显形、成长、护理、收获与年龄奖励。
- 加入基因育成、共生环、封存仓、生态复原台、调律砧与海晶双箱。
- 加入增生剂、螺鼓震、调律光灵箭、渔夫保育交易与河神钓鱼遭遇。
- 加入红石低潮维持：成长 10%、产出 15%、水与饱食消耗 25%，并暂停产生新的特殊需求。
- 支持 JEI、Jade、Curios 和车万女仆可选联动。
- 当前为公开测试版本，大规模自动化、旧女仆兼容和多人流程仍需继续验证。

## 辑录与揭秘 1.1.1

- 默认内容扩展为 7 个类别、120 条中文辑录条目。
- 辑录册新增潜行使用的“辑录揭秘”界面：线索 A 与线索 B 为并列输入，可配置一件或两件线索物品。
- 目录、阅读与揭秘界面完成重构；物品栏使用原版槽位与原版黑色提示框。
- 新增游戏内可视化编辑器，可维护类别、条目与线索组合；保存后保持当前编辑对象。
- 新增 `/reveal export-defaults`，可将内置默认内容导出到 `config/reveal/entries/` 供作者编辑。
- 新增 `/reveal doctor`，用于检查类别、物品、标签、配方和条目引用。
- 主配置迁移到 `config/reveal/reveal.json`，旧版 `config/reveal.json` 会自动迁移。
- 揭秘经验奖励支持根配置、类别和单条条目三级覆盖。
- 使用辑录册时会合并当前玩家与背包/副手辑录册中的已有进度，避免新书丢失可继续揭秘的记录。
- 修复揭秘按钮被 JEI 配方查询抢占的问题；现在会直接执行揭秘。

这里记录已经整理进 Wiki 的公开版本信息。未整理完成的内容不会写成正式功能。

## 潮汐委托

### 1.6.0

- 新增定期自动补充委托、等待接取时限与过期栏位冷却。
- 新增接取后无期限任务，并加入长期档案补给示例。
- 新增最多追踪三份委托的 HUD，可调整位置、缩放、透明度、边距和目标行数。
- 新增任务日志，记录成功、失败、放弃结果及对应游戏日。
- 新增委托目标达成与新委托送达的右上角提示。
- 新增 `/tc config` 游戏内配置中心，集中管理客户端显示和服务器常用规则。
- 重做玩家自定义委托发布与管理界面，加入三步流程、多行说明、数量调整和发布预览。
- 重做任务日志与完成总集排版。
- 修复死亡后完成总集累计进度丢失，以及玩家委托输入和数量编辑问题。
- 修复物品标签和群系标签在资源加载早期可能被错误拒绝的问题。
- 移除 Curios 可选联动、依赖和相关数据文件。

### 1.5.0

- 新增物品栏底部页签、`/tc open` 和可配置访问模式；默认不再强制携带委托板。
- 新增物品、标签、击杀实体、到达群系四类内置目标，并开放目标类型注册接口。
- 新增多目标组合规则、分批交付、只检查不消耗和物品组件匹配。
- 新增纯固定、纯可选和混合奖励方案；一个方案可包含多项奖励。
- 新增前置委托，以及仅一次、冷却、每日、每周等重复限制。
- 扩展游戏内可视化编辑器，并加入来源分类的新增、修改与安全删除。
- 加入覆盖新功能的默认演示委托。
- 修复多个击杀目标的进度相互覆盖；增加多目标保存与组合规则测试。
- 接入潮汐系列物品栏底部页签兼容布局，并保留当时版本的 Curios 联动。

### 1.4.0

- 新增阶段委托：静态任务支持 `stage_rules` 前置、排除与权重修正规则。
- 新增 `/tc stage`、`/tc doctor <玩家>` 与更完整的 `/tc reload` 诊断。
- 修复内置任务数据目录，改用 `tidal_commission_tasks`。
- 编辑器会保留已有 `stage_rules`；委托板和新手引导状态可跨死亡重生保留。
- 灰色组织唱片任务改用 `c:music_discs` 标签。
