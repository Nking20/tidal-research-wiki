# 更新日志

## 潮汐观测卡 1.0.21 之后

- 新增潮汐轮转玩法：已观测奖励可转入轮转界面，通过锁定、全刷新、双刷、三刷、偏流等操作形成牌型并结算奖励。
- 新增月相与潮汐点机制：轮转界面显示当前月相、潮汐点和牌型，相关成本、入场、月相修正和微调规则可配置。
- 新增多页观测卡与周期统计：观测卡支持多页，每页 12 张，并将显示文案调整为“本次开启 / Opened This Cycle”。
- 新增随机单等级模式：每张灰卡只显示一个随机等级，玩家不再总是手动选择 I 到 V。
- 新增隐藏等级模式：灰卡不提前显示真实等级，按配置默认档位支付观测成本，翻开后显示实际等级和奖励。
- 新增整页观测流程：`观测全部` 作用于当前页，服务器会先检查代券和货币是否足够，避免部分扣费后失败。
- 新增观测开奖动画开关：可在界面中开启或关闭观测动画，动画支持跳过。
- 调整观测卡与轮转界面的贴图表现：卡牌、按钮、背景和轮转面板改为贴图化显示，减少纯代码绘制。
- 调整服务端配置同步与热重载：服务器配置优先，客户端进入服务器后同步服务端规则，支持 `/trs reload` 和 `/trs doctor`。
- 调整默认配置：奖励池支持物品、标签、权重、数量区间、兑换价格区间和组件数据；轮转配置拆分为独立文件。
- 调整 JEI 和模组列表显示名：模组显示名改为英文 `Tidal Observation Card`。
- 修复不同 GUI 缩放和窗口尺寸下，观测界面、抽卡界面和轮转界面容易拉伸或错位的问题。
- 修复配置异常时直接覆盖旧配置的问题，重载失败时会保留旧配置并给出检查提示。
- 修复部分旧配置缺字段导致崩溃的问题，缺省字段会按默认值补齐。
- 修复观测、兑换、代券、Curios 携带观测卡、快捷键打开界面等服务端兼容问题。
- 修复观测卡 UI 中若干重影、层级遮挡、按钮 hover 区域和文字可读性问题。
