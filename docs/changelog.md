# 更新日志

## 辑录与揭秘 1.1.1

- 默认内容扩展为 7 个类别、120 条中文辑录条目。
- 辑录册新增潜行使用的“辑录揭秘”界面：线索 A 与线索 B 为并列输入，可配置一件或两件线索物品。
- 目录、阅读与揭秘界面完成重构；物品栏使用原版槽位与原版黑色提示框。
- 新增游戏内可视化编辑器，可维护类别、条目与线索组合；保存后保持当前编辑对象。
- 新增 `/reveal export-defaults`，可将内置默认内容导出到 `config/reveal/entries/` 供作者编辑。
- 新增 `/reveal doctor`，用于检查类别、物品、标签、配方和条目引用。
- 主配置迁移到 `config/reveal/reveal.json`，旧版 `config/reveal.json` 会自动迁移。
- 揭秘经验奖励支持根配置、类别和单条条目三级覆盖。
- 使用辑录册时会合并当前玩家与背包/副手辑录册中的已有进度，避免新书丢失可继续揭秘的记录。
- 修复揭秘按钮被 JEI 配方查询抢占的问题；现在会直接执行揭秘。

这里记录已经整理进 Wiki 的公开版本信息。未整理完成的内容不会写成正式功能。

## 潮汐委托

### 1.4.0

- 新增阶段委托：静态任务支持 `stage_rules` 前置、排除与权重修正规则。
- 新增 `/tc stage`、`/tc doctor <玩家>` 与更完整的 `/tc reload` 诊断。
- 修复内置任务数据目录，改用 `tidal_commission_tasks`。
- 编辑器会保留已有 `stage_rules`；委托板和新手引导状态可跨死亡重生保留。
- 灰色组织唱片任务改用 `c:music_discs` 标签。

### 1.1.4

- 加入委托总集，用于查看累计完成委托和里程碑奖励。
- 调整委托数据包备份，保留中文和英文任务内容。
- 优化部分界面贴图与布局。

### 1.1.2

- 默认可关闭玩家自定义委托入口。
- 默认可关闭指定来源栏位。
- 修正部分语言键和界面显示。

### 1.1.1

- 加入调度令和担保凭证。
- 支持玩家自定义委托。
- 支持服务端配置同步。
- 支持数据包和 KubeJS 扩展任务。
- 支持 Curios 可选联动。

### 1.0.3

- 修正委托板在不同窗口尺寸和 GUI 缩放下的显示问题。
- 接取后的任务卡加入详细与放弃按钮。
- 支持快捷键打开和关闭委托板。

## 潮汐观测卡
