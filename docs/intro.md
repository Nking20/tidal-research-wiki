# 潮汐研究社 Wiki

这里用于整理潮汐研究社系列 Minecraft 模组的公开说明。

当前已整理的内容以 **潮汐委托** 为主，包含模组概述、基础玩法、配置文件、数据包任务写法、玩家自定义委托和整合包魔改样例。
