# 潮汐研究社 Wiki

这里整理潮汐研究社系列 Minecraft 模组的公开文档。当前文档面向三类人：

- 普通玩家：了解模组的基础玩法和物品作用。
- 服务器管理员：了解服务端配置、双端同步和管理指令。
- 整合包作者：了解数据包、KubeJS、来源权重和任务 JSON 的写法。

## 当前已整理

- **潮汐培育**：九种水生样本、培养护理、基因 2.0、自动化与生态复原
- **炼狱培育**：潮汐培育的下界扩展，四种样本、组织采样与熔育槽温控
- **潮汐委托**：围绕委托板、任务来源、委托卡、玩家委托和数据包扩展的任务型模组。
- **潮汐观测卡**：围绕观测卡、等级、奖励池、轮转和服务器配置的抽取型模组。
- **辑录与揭秘 1.3.0**：通过研究站揭秘、背包持物或事件条件解锁内容，支持搜索筛选、进度共享和数据包扩展；提供 NeoForge 1.21.1 与 Forge 1.20.1 版。
