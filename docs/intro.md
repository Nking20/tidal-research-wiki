# 潮汐研究社 Wiki

这里是潮汐研究社系列 Minecraft 模组的静态文档站。

当前已整理的模组：

- **潮汐委托**：围绕委托板、任务卡、玩家自定义委托、数据包扩展和服务器配置的任务型模组。

计划中模组：

- **潮汐观测卡**：计划中，暂未整理可公开功能资料。
- **潮汐市场**：计划中，暂未整理可公开功能资料。

## 文档面向对象

- 普通玩家：安装、基础玩法、常见问题。
- 服务器管理员：服务端配置、双端同步、玩家委托管理。
- 整合包作者：数据包任务、KubeJS 注入、来源权重、奖励池和配方设计。
