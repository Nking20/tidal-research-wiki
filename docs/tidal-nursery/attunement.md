# 调律砧与装备分支

调律砧用于装备强化与配件加工

## 均衡、强化、稳固

放入锻晶或螺旋韧化片，通过增幅材料选择分支

| 分支 | 增幅材料 | 方向 |
| --- | --- | --- |
| 均衡 | 增幅槽留空 | 基础属性方案 |
| 强化 | 潮汐精华 ×1 | 更高属性收益 |
| 稳固 | 活性胶质 ×1 | 属性与基础耐久兼顾 |

按配方放入目标装备、两个耗材槽材料及所选增幅材料

## 操作步骤

1. 在 JEI 打开目标装备或材料的用途，找到调律砧分类
2. 放入待加工装备和对应耗材，按需要选择分支增幅材料
3. 清空产物槽，检查界面中的结果与材料需求
4. 材料与状态满足条件时自动加工，等待完成后取出结果

锻晶用于对应武器或护甲属性，螺旋韧化片用于盔甲韧化，同一效果可能有单件次数限制，实际数值与可加工次数以界面和装备提示为准

## 其他调律用途

调律砧还处理精细采样网、遮光配件、发光材料、箭矢、耐久与采掘等相关配方

安装炼狱培育时，也可通过配方为菌膜滑翔伞选择远航、灵巧或疾速翼型，材料与倍率集中见[滑翔伞调律](../infernal-nursery/travel.md#三条互斥调律)

整合包作者增加固定加工配方时，见[数据包扩展](./datapack.md)

## 材料齐了仍不加工

先清空输出，确认原料数量、目标装备类型及次数限制，再检查增幅槽

按配方核对增幅槽，需要留空时取出槽内物品
