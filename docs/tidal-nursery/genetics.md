# 基因系统 2.0

操作流程：**采集基因 → 保存档案 → 选择组合 → 重构前体 → 培养查看结果**

## 六个位点分成三组

| 组 | 潮汐样本 | 炼狱样本 |
| --- | --- | --- |
| 体型 / 韧性 | 体型、韧性 | 体型、韧性 |
| 代谢 / 产能 | 代谢、产能 | 代谢、产能 |
| 物种拓展 | 光照耐受、环境亲和 | 耐温、炼狱环境亲和 |

每条记录是**同物种、同一组的两个位点组成的完整组合**，写入时整组选用

前体不公开原始基因，显形后在设备详情界面悬停对应文字，查看完整效果

## 1 采集基因

最方便的方式是手持 **空白基因载体**，直接右键放有成熟样本的培育皿或熔育槽

也可以在基因育成槽的**基因提取**页放入成熟瓶装样本和空白载体，保持输出槽为空，点击提取

每次消耗一个空白载体，得到该样本的完整基因记录，**不消耗成熟样本**

炫彩和直接诱导标记不作为载体中的组合记录

## 2 保存档案

打开基因育成槽的**基因档案**页，放入记录载体并点击导入

载体按物种拆成三组组合并保存，已收藏的组合可按物种和组查看，选择记录后可确认删除

每次导入消耗一个记录载体，相同组合在档案中保存一条

档案保存在各自的基因育成槽中，随设备数据保存

## 3 选择组合并重构

1. 在**前体重构**页放入待修改的卵囊、卵簇等前体
2. 点击右侧的组，再选择已收藏的同物种组合
3. 按需要选择一组、两组或三组，未选择的组保留原值
4. 放入定向繁育剂，核对材料数量、写入目标与时间
5. 确保输出槽为空，点击开始重构，完成后取出前体
6. 将前体放回培育皿或熔育槽，显形后查看实际基因效果

| 选择组数 | 定向繁育剂 | 默认时间 |
| --- | --- | --- |
| 1 | 1 | 60 秒 |
| 2 | 2 | 90 秒 |
| 3 | 3 | 120 秒 |

每个选中的组都按一次写入计费，即使组合恰好与前体原值相同

核对目标组合和费用后开始重构，显形后可在详情中查看结果

## 基因怎样影响培养

| 位点 | 实际影响 |
| --- | --- |
| 体型 | 展示体型、成长、消耗和部分特殊事件成本 |
| 韧性 | 恶劣环境伤害、休眠恢复及特殊事件恢复 |
| 代谢 | 成长和产出速度，以及食物、水分消耗，部分类型受饱食影响 |
| 产能 | 周转速度、主产物或副产物倾向、特殊事件周期 |
| 光照耐受 | 适合光照的收益与不适合光照的损失 |
| 水生环境亲和 | 环境材料带来的成长、产出收益和无加成环境下的表现 |
| 炼狱耐温 | 冷热边界的扩展，不直接平移物种的最佳温区 |
| 炼狱环境亲和 | 自然温度、人工温控与配件的响应 |

不同基因类别各有取舍

例如小体型降低消耗，爆发代谢依赖较高饱食，副产倾向提高副产物权重

## 返祖诱导

手持返祖诱导剂，对**成熟且不在恢复中的样本设备**右键

成功时消耗一份，将一个尚未返祖的随机位点改成返祖类型，同一个体只能直接诱导一次，已经使用过或没有可诱导位点时会提示原因

诱导后的组合可以提取、收藏，再用于同物种前体重构，具体效果见位点提示

## 共生环印刻

从基因档案页进入共生环操作，放入共生环、合格成熟样本和稳定培养基，活珊瑚也可作为对应印刻材料

普通样本要求成熟、年龄至少 100、健康至少 40，且不在印刻疲劳中

每枚环最多 3 条效果，同物种最多 2 条，成功时消耗培养基，样本保留并进入疲劳，珊瑚材料会消耗

有 Curios 时佩戴生效，没有 Curios 时按背包中的有效共生环规则生效，具体效果看环的提示

## 无法操作时

| 提示或现象 | 检查 |
| --- | --- |
| 不能提取 | 是否成熟、是否放了空白载体、输出是否占用 |
| 本组没有组合 | 是否导入过同物种的有效记录 |
| 不能开始重构 | 是否为前体、是否已选择组合、定向繁育剂是否足够 |
| 机器正在加工 | 等待当前操作完成，不要重复提交 |
| 无法识别基因记录 | 保留原物品和存档，按[兼容说明](./compatibility.md)处理 |
