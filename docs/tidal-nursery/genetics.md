# 基因育成与共生环

## 基因育成槽

潮汐基因育成槽使用两个同物种成年样本作为亲本，再消耗一种培养介质产生杂交胚体。亲本必须达到 100 龄且健康至少为 40，并且不能处于繁育疲劳中。

| 培养介质 | 育成倾向 |
| --- | --- |
| 稳定培养基 | 均衡继承 |
| 活性胶 | 偏向代谢与产能 |
| 温和复苏剂 | 偏向韧性 |
| 矿物基质 | 偏向体型与环境亲和 |

两个亲本必须属于同一物种。育成槽前方还需要保留足够的展示空间。

## 共生环刻入

同一台机器也能把成年样本的代表性基因刻入共生环。放入共生环、成年样本和稳定培养基后开始处理。

- 一枚共生环最多保存 3 条效果。
- 同一物种最多重复刻入 2 次。
- 效果强度取决于该物种对应的关键基因，不是所有基因的简单平均。

| 物种 | 读取的关键基因 | 玩家效果 |
| --- | --- | --- |
| 普通水母 | 代谢 | 水中移动效率 |
| 小鱿鱼 | 代谢 | 潜行速度 |
| 发光鱿鱼 | 光照耐受 | 水下挖掘速度 |
| 珍珠贝 | 体型 | 最大生命 |
| 海葵 | 产能 | 攻击伤害 |
| 鹦鹉螺 | 环境亲和 | 氧气利用 |
| 晶簇蟹 | 韧性 | 盔甲韧性 |

## Curios 规则

Curios 不是强制前置：

- 安装 Curios 时，可以通过对应饰品栏装备共生环。
- 没有安装 Curios，或没有装备戒指时，只读取主背包顺序中最靠前的一枚共生环。
- 背包内放很多共生环不会让它们全部同时生效。
