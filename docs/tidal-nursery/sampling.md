# 采样与开局

## 开局准备

先制作简易采样网和潮汐培育皿。收获手套使用皮革、铜锭、铁锭和线等原版材料制作，不需要先取得培育产物，因此不会形成“必须先收获才能制作收获工具”的闭环。

配方建议通过 JEI 查看；没有 JEI 时也可以使用原版配方书。

## 直接取得浮游残渣

手持采样网右键海草、高海草或海带，会破坏对应植株并得到 `5～12` 个浮游残渣。海带会从玩家点击位置向上找到植株顶端进行采集。

这条路线适合只想取得基础原料的玩家：它不会额外强塞样本，也没有样本保底。

## 水域采样

对水源使用采样网并完成采样动作，可以得到浮游残渣或一种前体。环境会改变各前体的相对机会：

| 环境 | 更有利的结果 |
| --- | --- |
| 水草丰富 | 胶质卵囊；白天也更容易出现刺芽 |
| 较深且昏暗 | 墨色卵囊 |
| 沙质水底 | 幼贝簇 |
| 满月夜间 | 胶质卵囊；精细网在深水中还有额外鹦鹉螺机会 |
| 新月夜间 | 墨色卵囊；精细网更容易取得微光卵囊 |
| 雨天或雷雨 | 墨色卵囊；雷雨也会提高微光卵囊机会 |
| 黎明或黄昏的沙底 | 幼贝簇 |

环境扫描向下最多检查 12 格，不需要为了采样建造非常深的竖井。

## 简易网与精细网

- **简易采样网**：前期工具，可取得浮游残渣、胶质卵囊、墨色卵囊、幼贝簇和刺芽。
- **精细采样网**：动作更快，降低残渣权重并提高各类前体权重；在至少 6 格深的水域中才有机会取得鹦鹉螺卵簇和微光卵囊。
- **晶簇蟹卵团**：不在普通水域采样池中，通过紫水晶碎片与蜘蛛眼合成。

采样没有“连续失败后必出样本”的保底。这样只采残渣的玩家不会被迫背上额外的养育负担。

## 第一次培育

1. 给空培育皿加水。
2. 放入一种前体。
3. 等待约 60 秒完成显形。
4. 根据显形后的食性准备浮游类或藻类饲料。
5. 关注准星提示、详细界面或 Jade 信息，及时补水和处理护理需求。

每个培育皿一次只培育一个样本。
