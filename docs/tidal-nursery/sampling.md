# 采样与开局

## 先准备基础工具

简易采样网使用 **2 根木棍、3 根线**，摆法如下

```text
空 线 线
空 棍 线
棍 空 空
```

潮汐培育皿使用玻璃、铜锭和碗，不需要水生植物，放置新的培育皿会有 800 mB 水

```text
玻璃 空   玻璃
铜锭 碗   铜锭
空   玻璃 空
```

## 采植物和采水是两个操作

| 操作 | 结果 |
| --- | --- |
| 对海草、海带直接右键 | 打掉植物并取得 5～12 份浮游残渣 |
| 对水体长按右键 | 完成一次水体采样，可能取得前体或残渣 |
| 普通打碎海草 | 按对应掉落规则取得海草碎屑 |
| 剪刀剪海草 | 保留海草原有剪取用途 |

**植物采集优先于水体采样**，两种采样网都如此，不需要潜行

想在水草附近寻找样本时，把准星移到水体，避免一直点中植物

浮游残渣与海草碎屑是不同物品，前者用于基础饲料辅料，后者可替代饲料中的植物材料，配方见[食性与饲料](./feeding.md)

## 按环境寻找样本

下表是更容易命中对应栖息地的条件，不代表每次采样必定成功

| 目标 | 建议位置与条件 |
| --- | --- |
| 普通水母 | 夜晚、有至少 3 处水生植物的水域，河流也可以 |
| 小鱿鱼 | 较深的水域，深度至少 4，暗处更有利 |
| 珍珠贝 | 沙质水底 |
| 海葵 | 白天、水生植物较多的水域 |
| 鹦鹉螺 | 精细采样网，沙底深水，深度至少 10 更容易匹配 |
| 发光鱿鱼 | 精细采样网，深度至少 6，亮度不高于 7 |
| 晶簇蟹 | 精细采样网，石质水底，深度至少 4 |
| 美西螈 | 精细采样网，繁茂洞穴内的适合底质水域，深度至少 2 |
| 海龟 | 取得原版海龟蛋作为前体，也可从流浪商人寻找瓶装样本 |

栖息地判断有先后顺序，例如夜晚密集水草更偏向水母，精细网也不会无视环境直接抽取全部稀有种

满月夜、新月夜、雨天、雷雨和晨昏会改变部分权重，精细网降低残渣权重并提高部分样本权重，仍会出现残渣

## 前体怎样变成样本

把胶质卵囊、墨色卵囊等前体放入培育皿，默认约 60 秒完成显形

前体在物品提示中不公开具体基因，显形后打开设备详情查看食性、炫彩和基因，随后按[培育皿与护理](./culture-dish.md)培养

已经装着样本的培育皿不能再放入第二份前体，需要先用封存瓶潜行右键取出原样本
