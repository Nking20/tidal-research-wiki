## 特殊事件

| 物种 | 事件方向 | 照料重点 |
| --- | --- | --- |
| 普通水母 | 胶质脉冲 | 水量和健康 |
| 小鱿鱼 | 喷墨 | 饱食与水量 |
| 珍珠贝 | 孕珠 | 较高健康、饱食与水量 |
| 海葵 | 共生绽放 | 健康与护理 |
| 鹦鹉螺 | 壳体生长 | 健康与水量 |
| 发光鱿鱼 | 发光 | 合适光照与水量 |
| 晶簇蟹 | 蜕壳 | 饱食与护理 |
| 美西螈 | 再生 | 健康与饱食 |
| 海龟 | 晒背蜕甲 | 合适光照、健康与水量 |
| 青蛙 | 产胶事件 | 成年、饱食与护理 |

特殊事件按各自条件和周期结算，奖励在 JEI 的对应物种条目中查看

事件暂停时，按界面显示的原因处理

## 炫彩与基因

同物种可以有不同炫彩和基因，炫彩在样本详情和 Jade 中查看，具体基因效果在详情文字的悬浮框中查看

显形后可查看六个位点，基因载体记录三组基因组合

想保留某个组合，先将个体培养到成熟，再[提取并保存档案](./genetics.md)
