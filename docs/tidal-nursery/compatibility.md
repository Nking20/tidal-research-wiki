# 安装、配置与问题排查

本组文档按潮汐培育 **1.0.4-alpha** 本地代码整理，Minecraft **1.21.1**，NeoForge，Java **21**

## 安装与联动

GeckoLib 是运行依赖，当前工程使用 4.9.3，实际允许版本范围以发布包的模组元数据为准

| 可选模组 | 用途 |
| --- | --- |
| JEI | 工作台、培养、喂食、基因、调律、复原和珊瑚转化等分类 |
| Jade | 显示状态、炫彩、介质与事件信息，不列出六个位点 |
| Curios | 共生环饰品槽 |
| 车万女仆 | 照料任务与物流 |
| 炼狱培育 | 熔育槽、四种下界样本和温控基因拓展 |

客户端与服务器应安装相容版本，替换 JAR 前关闭游戏，同一实例不要同时留两份同模组文件

## 配置位置

- 采样、培养、饲料和基础数值：`config/tidalnursery-common.toml`
- 河神：`config/tidalnursery/river_god.json5`
- 炼狱温控与事件：[炼狱配置说明](../infernal-nursery/compatibility.md)

本 Wiki 的时间按正常 20 TPS 计算，服务端卡顿、配置和基因效果都会改变玩家感受到的时间

## 基因旧数据

基因 2.0 使用类别、三组双位点记录和按物种保存的档案，旧版范围载体、双亲规则不能直接照旧操作

当前实现包含旧格式识别与保留路径，不应手动删掉未知的样本或档案字段来“修复”它们

如果设备提示无法识别或存在待兼容记录，请保留原物品、原世界和日志，记录旧版及当前版本，再确认迁移支持范围

升级前保留完整世界备份，模组能加载不等于任何第三方修改过的数据都已安全转换

卸载炼狱培育会使其注册物品、实体和样本物种缺失，不能当作数据迁移方式

## 常见问题

| 问题 | 先检查 |
| --- | --- |
| 海草碎屑紫黑方格 | 当前实例实际安装的 JAR 是否正确、是否有旧资源包覆盖，查看资源加载日志 |
| 采样一直是残渣 | 是否一直对着植物右键，目标栖息地是否匹配，是否使用精细网 |
| 前体看不到基因 | 正常，显形后看设备详情 |
| 不能导入档案 | 是否是有效的记录载体，而非空白载体或旧范围格式 |
| 重复记录被消耗 | 正常，重复导入仍收费但不会生成重复条目 |
| 重构没反应 | 检查同物种档案、选中组、定向繁育剂、输出槽和忙碌状态 |
| 成年事件不动 | 看事件暂停原因，处理饱食、健康、水量、温度或护理，并腾出成品空间 |
| 新皿没有水 | 确认是全新物品还是保留了空介质的搬运物品、旧设备 |

反馈时提供游戏、加载器、两个模组版本，复现步骤和 `logs/latest.log` 对应时间段

文档构建通过只说明页面和链接有效，不能代替旧存档、服务器重启与多人同步的游戏验收
