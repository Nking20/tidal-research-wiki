# 配置、联动与已知限制

## 可选联动

| 模组 | 作用 | 是否强制 |
| --- | --- | --- |
| JEI | 展示配方、培育收获与相关说明 | 否 |
| Jade | 准星指向培育皿时显示状态 | 否 |
| Curios | 提供共生环饰品栏 | 否 |
| 车万女仆 | 自动护理、收获和海晶箱物流 | 否 |

缺少这些模组不会阻止潮汐培育加载。没有 Curios 时，背包中最靠前的一枚共生环仍可生效。

## 配置文件

普通培育与采样数值由 NeoForge 通用配置管理，主要包括：

- 前体显形时间、成长检查间隔和基础成长/产出；
- 护理需求间隔和休眠恢复时间；
- 饲料效果与错误饲料惩罚；
- 两类采样网速度、采样权重和环境加成；
- 各物种颜色基因权重。

河神使用独立的 `config/tidalnursery/river_god.json5`。联机环境以服务端规则为准，客户端不应自行假定采样概率或河神奖励。

## 当前已知限制

- `0.1.0-alpha` 尚缺少大规模公开服务器的长期压力验证。
- 较早存档的女仆可能残留旧寻路状态；当前版本具有保守自愈，但仍应保证培育皿旁有可站立空间。
- 密集培育皿、海晶双箱跨半箱物流、河神中断保护和螺鼓震仍是发布测试重点。
- 红石低潮维持的频繁开关和多种增益叠加已由专项逻辑测试覆盖，但仍建议在复杂红石设备中观察实际表现。
- 少量物品的第一人称手持比例仍可能继续微调，不影响物品本身功能。

遇到问题时，请一并提供 Minecraft、NeoForge 和模组版本、已安装的可选联动、复现步骤，以及 `logs/latest.log` 中对应时间附近的内容。
