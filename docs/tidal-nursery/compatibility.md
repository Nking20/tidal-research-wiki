# 安装、配置与问题排查

潮汐培育 **1.0.4-alpha** 适用于 Minecraft **1.21.1 NeoForge**，需要 Java **21** 和 GeckoLib

## 安装与联动

GeckoLib 使用版本以发布包的依赖要求为准

| 可选模组 | 用途 |
| --- | --- |
| JEI | 工作台、培养、喂食、基因、调律、复原和珊瑚转化等分类 |
| Jade | 状态、炫彩、介质与事件信息 |
| Curios | 共生环饰品槽 |
| 车万女仆 | 照料任务与物流 |
| 炼狱培育 | 熔育槽、四种下界样本和温控基因拓展 |

客户端与服务器安装相容版本，每个实例保留一份对应模组 JAR

## 配置位置

- 采样、培养、饲料和基础数值：`config/tidalnursery-common.toml`
- 河神：`config/tidalnursery/river_god.json5`
- 炼狱温控与事件：[炼狱配置说明](../infernal-nursery/compatibility.md)

文档数值采用默认配置，时间按 20 TPS 计算，整合包配置与数据包可覆盖对应规则

## 数据兼容

升级前备份世界，遇到无法识别的样本或档案时保留原物品、世界和日志，提供来源版本以便排查

含有炼狱物品、实体或档案的世界需要保留对应模组

## 常见问题

| 问题 | 检查 |
| --- | --- |
| 采样一直是残渣 | 准星是否指向植物，栖息地是否匹配，是否使用精细网 |
| 不能导入档案 | 是否为有效的记录载体 |
| 重构无法开始 | 同物种档案、选中组、定向繁育剂、输出槽和加工状态 |
| 成年事件暂停 | 按显示原因处理饱食、健康、水量、温度或护理，并腾出产物空间 |

反馈时提供游戏、加载器、模组版本，复现步骤和 `logs/latest.log` 对应时间段
