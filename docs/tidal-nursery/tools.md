# 工具、药剂与自定义样本

## 日常工具

| 工具 | 用途 |
| --- | --- |
| 简易 / 精细采样网 | 植物直接右键取残渣，水体长按右键采样 |
| 清洁刷 | 清洁培养设备与对应物种需求 |
| 收获手套 | 按设备状态收取培养产物 |
| 封存瓶 | 潜行键 + 右键，取出并封存培育皿或熔育槽样本 |
| 组织采样器 | 炼狱扩展工具，对符合条件的生物直接采样 |

潜行键使用玩家当前绑定的按键，不必固定为 Shift

## 增生剂

用于已经显形、尚未成熟且没有休眠的样本，默认立即增加 5 成长，并增加 5 分钟增生时间

增生期间默认成长 ×1.6、产出 ×1.1，同时食物和水消耗 ×1.25，先保证补给再使用

前体显形中、成熟或休眠时不能按普通幼体规则使用，失败原因看设备提示

## 返祖诱导剂与定向繁育剂

返祖诱导剂直接用于成熟样本，每个个体只能直接诱导一次

定向繁育剂放入基因育成槽支付重构费用，每个选中组消耗 1 份，两者用途不同，重构不需要返祖诱导剂

具体流程见[基因系统 2.0](./genetics.md)，五种药剂摆放见[材料说明](./materials.md)

## 其他功能物品

螺鼓、箭矢导能和其他功能工具的原料、作用对象与次数限制在 JEI 用途和物品提示中查看

装备升级集中在[调律砧](./attunement.md)，破碎刷怪笼交给[生态复原台](./progression.md)

## 创造模式自定义样本

自定义样本工具用于创造模式测试，不是生存培养的免费修改入口

- 对空气使用：打开创建与导出界面
- 对放有样本的培育皿或熔育槽右键：直接编辑这个个体
- 实时编辑锁定物种，修改后点击应用，服务器确认后才算生效
- 还原参数用于撤销尚未应用的调整

修改当前个体不会把设备库存、介质和事件状态整体重建，未识别的旧基因应保留，不能为了强制编辑而删掉原始记录
