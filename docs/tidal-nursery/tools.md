# 工具与消耗品

## 采样与收获

- **简易采样网**：基础水域采样工具，也可从海草和海带取得浮游残渣。
- **精细采样网**：采样更快、残渣权重更低，并解锁深水稀有前体。
- **收获手套**：玩家从培育皿取走成熟留存的主要工具。配方只使用原版材料。
- **封存瓶**：右键带有样本的培育皿，把当前样本及状态封装成可携带物品；再次放入空皿时会返还空瓶。

## 护理工具

- **清洁刷**：处理清洁需求；成功清洁后带来护理收益，而不是普通右键装饰动作。
- **营养滴剂、海盐修复液、温和复苏剂**：用于不同强度的健康恢复。
- **基础与进阶饲料**：正确偏好提供更多饱食；满级前后的渔夫会出售部分进阶饲料。

## 增生剂

增生剂只能用于尚未成熟、已经显形且没有休眠的样本。成功使用后：

- 立即增加 `5` 点成长；
- 维持 5 分钟的成长速度 `+60%`；
- 产出速度 `+10%`；
- 水与饱食消耗 `+25%`。

空皿、仍在显形、已经休眠或已经成年的样本不会消耗增生剂，并会给出失败原因。

## 螺鼓震

螺鼓震是一件对付幻翼的主动工具：

- 使用后吸引玩家周围 16 格内的幻翼；
- 幻翼进入玩家 3 格范围时直接死亡；
- 只有成功击杀至少一只幻翼才进入冷却；
- 没有命中有效目标时不会白白触发冷却。

## 调律光灵箭

调律光灵箭以原版光灵箭为基础，用于调律相关战斗流程。调律砧可强化它的额外伤害，当前强化上限为 `+16`。
