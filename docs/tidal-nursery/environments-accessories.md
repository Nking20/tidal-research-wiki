# 环境与配件

培育皿有两个配件槽和一个环境槽，先满足食物、水量和光照，再考虑提高效率

## 培育皿配件

| 配件 | 用途 |
| --- | --- |
| 遮光罩 | 降低有效光照，适合喜阴样本 |
| 深遮光罩 | 提供更强遮光 |
| 透明皿盖 | 减少水分流失和部分环境伤害，同时影响雨水补充 |
| 气泡石 | 提高产出表现 |
| 稳定环 | 减缓不良状态变化，降低照料压力 |

配件的数量与叠加效果见界面提示

个体具有喜光、喜阴或中性偏好，光照耐受基因调节环境适应效果

## 环境材料

水生植物、花、活珊瑚、珊瑚砂床、矿化基质和发光藻等具有不同环境效果，具体材料在 JEI 中按用途查看

环境亲和决定如何利用已有加成，有的偏成长，有的偏产出，也有适合低投入环境的类型

按样本的偏好和环境亲和选择材料

## 潮涌共鸣

附近有效的潮涌核心可以提供共鸣加成，界面显示共鸣状态时表示已生效，核心必须真正激活

默认按水平半径 32 格搜索，扫描有间隔，刚放下核心后可稍等片刻再看状态

## 生物液

生物液可作为培育介质，降低饱食消耗 25%，培养时正常消耗液体

把水换为生物液前应先处理原有介质，不能把不同液体任意混在同一槽中

制作流程见[材料与消化器](./materials.md)，炼狱设备使用独立的[温控介质规则](../infernal-nursery/molten-vat.md)
