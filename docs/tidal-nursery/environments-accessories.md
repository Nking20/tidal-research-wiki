# 培养环境与配件

潮汐培育皿具有 **两个配件槽** 和 **一个环境槽**。配件用于修正光照、耗水、健康损伤、产出或活跃度损失；环境则更偏向特定样本的成长和生产。

每个槽位最多放入一个物品。两个配件槽接受相同的物品，因此同一种配件可以安装两份并叠加；环境槽只能安装一份。拆除培育皿时，配件和环境物会正常掉落。

## 配件

| 配件 | 单件效果 | 两件叠加时 | 注意事项 |
| --- | --- | --- | --- |
| 遮光罩 | 内部光照降低 `8` | 降低 `16` | 适合喜阴样本；装得过多也可能让中性或喜光样本光照不足。 |
| 强效遮光罩 | 内部光照降低 `15` | 降低 `30` | 通常一件已经足以制造深度遮光。可与普通遮光罩叠加。 |
| 清澈皿盖 | 每次耗水变为原来的约 `75%`；健康伤害约减半 | 耗水约为 `56%`；健康伤害约为四分之一 | 安装任意皿盖后，培育皿不能从降雨中集水。它降低伤害，不会直接治疗样本。 |
| 增氧石 | 在当前状态产出倍率上增加 `0.12` | 合计增加 `0.24` | 只提高生产进度，不会加快年龄成长。 |
| 稳定环 | 每次活跃度损失约减半 | 再减半，最低仍损失 `1` 点 | 对错误喂食、饥饿、搬运和部分治疗造成的活跃度损失均有效。 |

配件效果按培育皿中的实际数量计算。两个配件槽可以混装，例如“遮光罩 + 增氧石”同时控制光照并提高产出。

## 环境

环境槽接受专用培养基，也接受部分原版方块或物品标签。环境亲和基因只在安装环境时生效：每 `+1` 点环境亲和，会把该环境的成长和产出倍率再提高约 `0.2%`；负值则相应削弱。

| 环境类型 | 可放入的典型物品 | 主要作用 |
| --- | --- | --- |
| 水生植物 | 海草培养基、海草、海带、海泡菜、睡莲、苔藓块 | 浮游食或藻食样本成长 `+8%`；浮游食样本产出 `+4%`；每次耗水减少 `5 mB`，并缓解这两类样本的饱食消耗。 |
| 花草 | 任意原版花卉 | 健康低于 `80` 时成长 `+5%`；满足自然恢复条件后，健康恢复检查由约 `30` 秒缩短为约 `10` 秒。 |
| 珊瑚砂床 | 珊瑚砂床 | 珍珠贝、鹦鹉螺和晶簇蟹产出 `+16%`，其他样本 `+2%`；上述三类样本的副产物概率额外 `+8%`。 |
| 矿化基质 | 矿化基质 | 所有样本产出 `+10%`、副产物概率 `+4%`，但每次饱食消耗增加 `1`。 |
| 其他矿物 | 原版矿石、粗矿块以及兼容矿石标签 | 珍珠贝、鹦鹉螺和晶簇蟹产出 `+8%`，其他样本 `+4%`。没有珊瑚砂床和矿化基质的额外副产物加成。 |
| 微光藻 | 微光藻团 | 内部光照提高 `4`；喜光样本产出 `+8%`，其他样本 `+2%`；稳定收获时，炫彩染料概率额外 `+10%`。 |

## 怎么选择

- **前期缺水、缺饲料**：水生植物最稳妥，尤其适合普通水母、海葵等浮游或藻食样本。
- **样本健康经常偏低**：使用花卉环境，并搭配清澈皿盖减少后续伤害。
- **培养珍珠贝、鹦鹉螺或晶簇蟹**：珊瑚砂床通常是收益最高且没有额外饱食代价的选择。
- **只追求通用产量**：矿化基质更直接，但需要准备更多饲料。
- **培养喜光样本或追求染料**：选择微光藻，并留意它可能让喜阴样本处于错误光照。
- **喜阴样本放在明亮区域**：优先安装遮光罩；不要因为可以叠加就默认装满两件。

环境和配件只修正培育表现，不会替代补水、喂食、合适光照或特殊护理。红石低潮、增生剂、潮涌共鸣与基因效果仍会和它们继续叠加。
