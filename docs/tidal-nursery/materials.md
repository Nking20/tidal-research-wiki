# 材料、消化器与早期皮革

## 早期皮革路线

1. 用采样网收集浮游残渣并开始培养水母
2. 用 **堆肥桶 ×1 + 泥土 ×1 + 铜锭 ×1**无序合成活性消化器
3. 投入受支持的有机原料，积累生物质
4. 取得生物碳基，与水母水母凝胶无序合成皮革

**生物碳基 ×1 + 水母凝胶 ×1 → 皮革 ×4**

这条路线不要求先养牛，具体有机原料的生物质价值在 JEI 的消化器分类中查看

## 活性消化器

消化器最多保存 2048 生物质，每批消耗 256，默认 6 秒产出生物碳基 ×4

原料价值不同，浮游残渣和海草碎屑也可以投入，但不要把一份碎屑当作一批基底

缺少生物质或成品槽堵塞时不加工，运行时有气泡反馈，停止时不会继续播放加工效果

## 主要产物用途

| 来源 | 材料 | 主要方向 |
| --- | --- | --- |
| 水母 | 水母凝胶、活性胶质 | 早期皮革、胶质材料、调律稳固分支 |
| 鱿鱼 | 墨液碎片、荧光墨囊 | 墨与照明相关加工、遮光配件升级 |
| 珍珠贝 | 珍珠碎片 | 珍珠材料与后续加工 |
| 海葵 | 刺胞纤维、活性胶质 | 功能材料与加工 |
| 鹦鹉螺 | 鹦鹉螺壳 | 螺旋韧化片等材料 |
| 晶簇蟹 | 晶簇甲片 | 护盾、采掘和调律相关强化 |
| 美西螈 | 美西螈黏液 | 对应培养与功能配方 |
| 海龟 | 海龟鳞甲 | 鳞甲相关配方 |

这是用途索引，普通产物、概率副产与特殊事件奖励应分开看，具体材料数量以 JEI 为准

## 生物液与生态展示舱

生物液通过培养加工取得，可用桶转移，用于培育介质与生态展示舱，具体配方查看 JEI 的培养加工分类

用作培育介质时减少饱食消耗 25%，不提高成长或产量，展示用途见[封存与生态复原](./progression.md)

## 五种药剂

| 物品 | 作用位置 |
| --- | --- |
| 生物催化剂 | 对应培养与加工配方，具体用途查 JEI |
| 繁育剂 | 保留物品兼容与现有配方用途，不代表旧双亲入口仍可用 |
| 定向繁育剂 | 基因育成槽重构，每组选用一份 |
| 返祖诱导剂 | 对成熟样本设备直接使用 |
| 增生剂 | 对培养中的样本使用，临时促进成长与产出 |

五种药剂也可摆放为立体瓶，对普通支撑面右键放置，同一位置可放 1～4 瓶，两瓶对角、三瓶三角、四瓶 2×2

对设备使用时优先执行相应功能，背包图标与放置、手持模型是不同的显示方式
