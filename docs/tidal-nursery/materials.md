# 材料、活性消化池与早期皮革

## 早期皮革路线

1. 用采样网收集浮游残渣并开始培养水母
2. 用 **堆肥桶 ×1 + 泥土 ×1 + 铜锭 ×1**无序合成活性消化池
3. 开盖投入受支持的有机原料，积累生物质后合盖
4. 取得生物碳基，与水母凝胶无序合成皮革

**生物碳基 ×1 + 水母凝胶 ×1 → 皮革 ×4**

有机原料的生物质价值在 JEI 的有机消化分类中查看

## 活性消化池

消化池最多保存 **8192 生物质**，每批消耗 **256**，经过 **120 ticks** 产出 **生物碳基 ×4**，20 TPS 下约为 6 秒

不同原料提供的生物质价值不同，浮游残渣和海草碎屑也可以投入

### 投料与开合盖

| 操作或状态 | 行为 |
| --- | --- |
| 潜行、空手右键 | 开盖或合盖，优先于取产物 |
| 开盖并手持有效原料右键 | 装入生物质 |
| 普通空手右键 | 取出产物 |
| 开盖 | 等待投料或暂停现有进度 |
| 合盖 | 原料足够且有输出空间时，处理本次授权的一批 |

### 每次合盖一批

| 合盖前储量 | 完成一批后的储量 |
| --- | ---: |
| 128 | 不足一批，等待 |
| 256 | 0 |
| 1024 | 768 |
| 8192 | 7936 |

完成后维持合盖停止，取出产物也不会授予下一批；需要重新**开盖 → 合盖**继续加工

中途开盖保留进度，再次合盖继续同一批；成品槽满时暂停，原料和产物在批次完成时一次结算

开盖可通过现有漏斗和物品接口投料，合盖拒绝新增原料；底部产物提取保持可用

比较器按储量相对 8192 的比例输出 0～15 级，满容量为 15，2048 生物质为 3

运行中可见少量气泡并听到发酵声音，开盖和批次完成后停止；Jade 显示储量、进度与开盖、堵塞或完成状态

海莴苣每个提供 2 点生物质，海葡萄每个提供 3 点，种植见[海洋园艺](./gardening.md)

## 主要产物用途

| 来源 | 材料 | 主要方向 |
| --- | --- | --- |
| 水母 | 水母凝胶、活性胶质 | 早期皮革、凉拌海蜇、缚团、胶质坐垫、调律稳固分支 |
| 鱿鱼 | 墨液碎片、荧光墨囊 | 墨云囊、墨与发光材料加工、遮光配件升级 |
| 珍珠贝 | 珍珠碎片 | 珍珠材料与后续加工 |
| 海葵 | 刺胞纤维、活性胶质 | 功能材料与加工 |
| 鹦鹉螺 | 鹦鹉螺壳 | 螺旋韧化片等材料 |
| 晶簇蟹 | 晶簇甲片 | 护盾、采掘和调律相关强化 |
| 美西螈 | 美西螈黏液 | 对应培养与功能配方 |
| 海龟 | 海龟鳞甲 | 鳞甲相关配方 |

这是用途索引，普通产物、概率副产与特殊事件奖励应分开看，具体材料数量以 JEI 为准

食品见[海洋食品](./food.md)，珊瑚石材、灯具与胶质坐垫见[建筑与照明](./building.md)，工具见[工具与药剂](./tools.md)

## 生物液与生态展示舱

生物液通过培养加工取得，可用桶转移，用于培育介质与生态展示舱，具体配方查看 JEI 的培养加工分类

用作培育介质时减少饱食消耗 25%，不提高成长或产量，展示用途见[封存与生态复原](./progression.md)

## 药剂

| 物品 | 作用位置 |
| --- | --- |
| 生物催化剂 | 对应培养与加工配方，具体用途查 JEI |
| 繁育剂 | 对成熟样本所在设备使用，条件见[工具与药剂](./tools.md#繁育剂) |
| 定向繁育剂 | 基因育成槽重构，每组选用一份 |
| 返祖诱导剂 | 对成熟样本设备直接使用 |
| 增生剂 | 对培养中的样本使用，临时促进成长与产出 |

药剂可摆放为立体瓶，对普通支撑面右键放置，同一位置可放 1～4 瓶，两瓶对角、三瓶三角、四瓶 2×2

对设备使用时优先执行相应功能，背包图标与放置、手持模型是不同的显示方式
