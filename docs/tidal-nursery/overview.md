# 潮汐培育

潮汐培育围绕水域采样、照料样本、收获材料和收藏基因展开

本文对应 **Tidal Nursery 1.0.4-alpha / Minecraft 1.21.1 NeoForge**，按 2026-10-17 本地代码整理，时间与数值均为默认规则，整合包配置和数据包可能覆盖它们

## 第一次游玩

1. 用木棍和线制作简易采样网
2. 对海草或海带直接右键，取得浮游残渣
3. 用残渣和植物材料制作浮游饲料、藻类饲料
4. 对水体长按右键采样，取得卵囊等前体
5. 制作并放下潮汐培育皿，将前体放入，等待显形
6. 按样本食性喂食，处理缺水、光照和护理需求
7. 成年后收获产物，用空白基因载体提取记录

新培育皿初始有 **800 mB 水**，容量 **1000 mB**，开局配方不需要海带

## 当前内容

- 九种水生样本，包括水母、两种鱿鱼、珍珠贝、海葵、鹦鹉螺、晶簇蟹、美西螈和海龟
- 基因提取、按物种保存档案、三组组合选择与前体重构
- 返祖诱导、炫彩收集和共生环印刻
- 循环泵站、活性消化器、珊瑚苗床、调律砧与生态复原台
- 封存携带、展示、保育交易与河神事件

安装[炼狱培育](../infernal-nursery/overview.md)后，增加四种下界样本和熔育槽温控培养，继续使用同一套基因档案系统
