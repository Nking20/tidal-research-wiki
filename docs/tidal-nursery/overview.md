# 潮汐培育

![潮汐培育图标](/img/tidal-nursery.png)

潮汐培育是一个围绕海洋样本采集、照料、繁育和生态复原展开的 Minecraft 1.21.1 NeoForge 模组。玩家需要建立能够持续供水和供料的育成区，而不是把培育皿当成无需维护的普通产物机器。

当前公开版本定位为 `0.1.0-alpha`。

## 核心流程

1. 制作简易采样网，在合适水域取得浮游残渣或样本前体。
2. 把前体放入潮汐培育皿，等待显形。
3. 维持水量、饱食、健康和合适光照，并处理临时护理需求。
4. 样本达到 100 龄后成为成年体，开始积累可收获产物。
5. 使用收获手套、漏斗或女仆取走成熟产物。
6. 用成年样本进行基因育成、共生能力刻入或生态复原。

## 运行需求

- Minecraft 1.21.1
- NeoForge 21.1.219 或兼容的更高版本
- Java 21

JEI、Jade、Curios 和车万女仆均为可选联动，不是基础玩法的强制前置。
