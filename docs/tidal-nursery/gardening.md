# 海洋园艺与悬绳种植

海葡萄和海莴苣是可移植、自然生长和重复采收的水下植物

## 寻找与移植

| 植物 | 寻找环境 | 种植物品 |
| --- | --- | --- |
| 海葡萄 | 普通、温暖、暖水及对应深海中的合适海床 | 海葡萄苗 |
| 海莴苣 | 普通、寒冷、暖水及对应深海中的岩壁或岩面 | 海莴苣 |

海葡萄产物可以直接无序合成海葡萄苗，比例为 **海葡萄 ×1 → 海葡萄苗 ×1**

把种植物品用于有效附着面，种植位置需要水源和可用空间

## 海葡萄

海葡萄苗可种在水下的沙子、红沙、沙砾、泥土或苔藓块顶面

| 阶段 | 外形与占用空间 |
| --- | --- |
| AGE 0 | 一格幼苗 |
| AGE 1 | 一格生长期 |
| AGE 2 | 两格高，枝条伸展，果串未成熟 |
| AGE 3 | 两格高，果串成熟 |

从 AGE 1 继续成长时，上方需要一格可用水源；保持上下两格水体和底部支撑

成熟后空手右键上半格或下半格，收获 **海葡萄 2～4 个**，植株回到 AGE 2，保留两格结构

破坏植株与右键采收的结果不同，重复采收时保留根部和上半格即可

## 海莴苣

海莴苣可附着在水下有效支撑的顶部或侧面，支持石头、安山岩、闪长岩、花岗岩、凝灰岩、方解石、深板岩，以及泥土、沙子、沙砾和苔藓块

部分石质楼梯也能作为支撑，实际被点击的面需要完整支撑，不能把所有楼梯面都视为合法附着面

共有 AGE 0～3 四个阶段，AGE 3 成熟，空手右键收获 **海莴苣 1～3 个**，回到 AGE 2

### 自然蔓延

成熟海莴苣可沿相同附着面的上下左右相邻位置蔓延，地面植株沿地面四邻方向蔓延

- 目标需要水源、合法支撑和空位
- 新植株从 AGE 0 开始
- 默认每次成熟植株随机刻有 5% 概率尝试蔓延
- 默认相连群落上限为 6 株，采收和破坏可控制范围
- 野生群落通常以 3～7 株生成，已有群落可按各自状态继续生长

蔓延参数见[配置说明](./compatibility.md#海洋园艺配置)

## 光照、苔藓与骨粉

两种植物均通过随机刻自然生长，所在区块需要处于有效随机刻范围

亮处成长机会较高，普通暗水环境仍可成长；附着在苔藓块上的自然成长机会更高

对未成熟且环境合法的植株使用骨粉，每次推进一个阶段，普通水下暗部也可以催熟；成熟植株使用骨粉不消耗骨粉

成长时间受随机刻速度和环境影响，不能把现实时间视为固定倒计时

## 悬绳架

配方产出 4 个悬绳架

```text
线 木板 线
空 木棍 空
```

悬绳架可以挂在完整底面下，或沿同一方向连接到附近岩壁或有顶部支撑的架子；每个架子沿架设轴向最多检查 4 格寻找有效支撑

### 种植步骤

1. 在水下搭好有支撑的悬绳架
2. 架子下方保留水源
3. 用海葡萄苗或海莴苣右键架子，消耗一份种植物品
4. 悬挂海葡萄还需向下预留第二格水源，AGE 2 开始向下占两格
5. 等待成熟，空手右键采收，植株回到 AGE 2

悬挂海葡萄每次收获 2～4 个，悬挂海莴苣每次收获 1～3 个；悬挂海莴苣保留单格种植形态

## 产物用途

- 海葡萄：直接食用、转为苗、制作沙拉和鱼卷，每个提供 3 点生物质
- 海莴苣：移植、制作料理、饲料和纸，每个提供 2 点生物质
- **海莴苣 ×4 + 浮游残渣 ×1 → 藻类饲料 ×7**
- **海莴苣 ×3 → 原版纸 ×2**，无序合成

料理与营养见[海洋食品](./food.md)，生物质处理见[材料与活性消化池](./materials.md)
