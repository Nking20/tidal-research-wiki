# 河神与漂流瓶

河神是潮汐培育中独立实现的一套稀有钓鱼遭遇。它与其他潮汐研究社模组中名称相同的玩法各自结算，配置和进度不会互通。

## 触发方式

玩家真正钓到物品时，默认有 `2%` 概率遇见河神。没有触发河神时，默认另有 `3%` 概率把本次结果替换为漂流瓶。

使用漂流瓶后，玩家下一次有效钓鱼必定遇见河神。无效抛竿不会浪费这次保证。

## 回答与风险

河神会针对本次钓获提出问题。界面始终提供一个无风险的原物返还选项，以及三个具有不同性格和风险的回答。

- 谨慎回答默认成功率较高，收益和惩罚都较温和。
- 贪婪回答默认成功率较低，但可能得到更强结果，也可能承受更明显的不利效果。
- 最终判定、奖励和惩罚都由服务端执行，客户端只负责显示和发送选择。

如果玩家在事件中死亡、掉线或界面异常中断，系统会尽量保护原始钓获物，避免因为界面流程丢失。

## 服务端配置

河神使用独立文件：

```text
config/tidalnursery/river_god.json5
```

服务器可以调整启用状态、遭遇与漂流瓶概率、回答成功率、效果持续时间，以及奖励和失败物品池。
