# 自动化与海晶箱

## 原版自动化

培育皿支持水流体能力，可以由兼容管道或其他自动化设备补水。下方放置漏斗时，成熟收获可以进入自动输出流程。

比较器按培育皿内的留存份数输出：

| 留存 | 信号强度 |
| --- | --- |
| 0/3 | 0 |
| 1/3 | 5 |
| 2/3 | 10 |
| 3/3 | 15 |

## 海晶箱

海晶箱遵循原版箱子的主要规则：

- 单箱 27 格；
- 同朝向相邻放置可组成 54 格双箱；
- 支持左右箱盖、阻挡检查、含水状态、比较器和拆分行为；
- 漏斗可以正常与箱体交互。

## 车万女仆联动

安装车万女仆后，可以启用潮汐培育的样本护理任务。女仆能够在工作范围内执行补水、喂食、治疗、清洁、特殊护理、收获和回箱。

女仆自带：

- 用于常规补水的水源；
- 等同收获手套的收获能力。

女仆必须从背包或可用库存取得：

- 饲料；
- 清洁刷；
- 治疗药剂；
- 样本提出的自身产物护理材料。

常规情况下，女仆在饱食低于 70 时喂食，在水量不高于 900 mB 时补水。样本处于紧急状态或明确提出需求时会按护理优先级处理。

海晶箱存在时，女仆会从箱中取得护理材料，并把收获产物存回可用格子。双箱的完整 54 格均可用于物流；所有海晶箱都装满时，女仆会暂停继续收获。

:::note 旧女仆兼容
较早存档中的女仆偶尔可能残留失效的寻路目标。当前版本会在约 5 秒没有进展后尝试温和清理并重新规划。若仍不工作，请先检查相邻落脚位置和通路是否畅通。
:::
