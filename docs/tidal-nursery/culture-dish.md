# 培育皿与护理

## 显形与封存

培育皿水槽容量为 **1000 mB**，新制作或创造取得的培育皿首次放置自带 800 mB 水，携带设备数据的物品按自身保存的介质恢复

前体入皿后默认显形 60 秒，之后进入幼体、成长、成熟等阶段，成长达到 100 时成年

用 **封存瓶 + 潜行键 + 右键**取出样本，保留个体状态，瓶装期间不继续培养，重新放入可继续照料

## 如何看界面

- 主界面看阶段、健康、饱食、水量、成长与产出
- 详情界面看食性、炫彩和六个基因位点，悬停整行文字查看具体效果
- Jade 用于看现场状态和炫彩，不列出六个位点
- 按状态栏显示的原因处理培养问题

默认每 10 秒检查一次成长，基础成长量为每次 0.6，基因、光照、环境和药剂会改变实际速度

## 基本照料

| 问题 | 处理 |
| --- | --- |
| 饱食不足、严重饥饿 | 按食性喂合适饲料，见[饲料表](./feeding.md) |
| 水量不足 | 用水桶或流体接口补水，也可使用循环泵站 |
| 光照不适合 | 移动设备、改变周围照明，或安装遮光配件 |
| 出现护理需求 | 按提示使用清洁刷、照料工具或对应护理材料 |
| 产物留存达到 3/3 | 收取留存产物，给下一批腾出空间 |
| 休眠 | 先消除原因，再等待恢复，恢复默认约 3 分钟 |

健康和饱食低于 20、水量严重不足等情况会影响培养，持续恶劣状态会导致休眠

休眠后先处理饥饿、光照等原因，再等待恢复

默认护理需求间隔约 8～12 分钟，处理需求比反复投喂更重要

## 收获和特殊事件

成年后继续积累产出，产物留存最多 3 批，收获时按设备提示使用收获手套等对应工具，也可用自动化提取已保存的产物

成年后继续累计培养年龄

不同物种还有孕珠、脉冲、喷墨、蜕壳等事件，查看其进度旁的暂停原因，补足健康、饱食、水量并满足光照与护理条件

普通产出和特殊事件分别结算，完成的产物需要存储空间，及时收取留存产物

## 红石低潮维持

培育皿受红石信号供电时进入低潮维持，默认成长速度为普通的 10%、产出速度为 15%、食物与水消耗为 25%，并抑制新护理需求

低潮维持适合降低养护负担，封存瓶可暂停个体培养

自动补给布局见[自动化](./automation.md)，光照配件和环境材料见[环境与配件](./environments-accessories.md)
