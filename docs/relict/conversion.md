# 岁月尘

岁月尘（`relict:temporal_dust`）可以把一部分旧世界的材料、食物和建材换成同类原版物品。

## 获得岁月尘

- **采矿**。在旧世界正常采出矿物时，旧煤矿、红石矿、青金石矿、钻石矿和红宝石矿有 5% 概率额外掉一份。
- **翻补给箱**。旧屋、地牢、矿井和两座神庙都有机会开出，见[遗迹与战利品](./structures.md#岁月尘的箱子来源)。
- **和淘气鬼互动**。提高信任后，完成捉迷藏或成功带路有机会拿到 1～2 份。详见[淘气鬼的规则](./mobs.md#淘气鬼的详细规则)。

## 它能换什么

每份岁月尘转换四个同种旧物品，得到四个原版对应物。转换从旧界单向通往原版，工具、防具和带自定义数据的物品不参与，改过名的方块也不会被消耗。能换的物品可以直接在 JEI 里查看岁月尘的用途。
