# 遗物与历史玩法

## 岁月尘

岁月尘 `relict:temporal_dust` 可从部分旧世界矿石、遗迹补给箱和[淘气鬼](./mobs.md#淘气鬼)处获取。旧煤、红石、青金石、钻石和红宝石矿在正常掉落矿产时，有 5% 概率额外掉落一份岁月尘。

转换覆盖 47 对方块，包括常见石土、橡木与白桦木、丛林木、玻璃、砖块、雪与冰，以及部分矿物储存块。转换只接受没有额外数据组件的物品。

| 操作 | 做法 |
| --- | --- |
| 转换 1 个现代方块 | 工作台放一个可转换方块和一份岁月尘 |
| 转换 8 个现代方块 | 工作台八格分别放同一种方块，剩下一格放岁月尘 |
| 还原 1 个历史方块 | 在切石机选择对应的现代方块 |
| 还原 8 个历史方块 | 工作台八格分别放同一种历史方块，保留一个非中心空格 |

## PE 相机

PE 相机 `relict:pe_camera` 可在旧地牢补给箱中找到。将相机放在方块顶面，右键启动约 4 秒倒计时。照片以截图文件的形式保存到你的客户端 `screenshots` 文件夹。想再次取走相机时，可在生存模式下打掉它。

## 下界反应核

下界反应核 `relict:nether_reactor_core` 需要六个铁锭和三颗原版钻石。工作台中列放三颗钻石，左右两列各放三个铁锭。铁锭可以用原版铁锭或旧界铁锭。

在空旷处搭三层 3×3 结构。激活会生成下界岩塔，覆盖塔体范围内的方块。留出塔体空间，并让同维度的非旁观玩家靠近核心、站在相近高度。

```text
顶层        中层        底层
空 石 空    石 空 石    金 石 金
石 石 石    空 核 空    石 石 石
空 石 空    石 空 石    金 石 金
```

「石」为圆石，「金」为金块，均可用对应旧界变体。「空」处留空。搭好后空手右键核心，触发约 90 秒的事件。期间会生成物资和猪人，塔上层会出现野火。结束后核心耗尽。

## 技术遗物

技术遗物有自己的创造模式物品栏页，包括火、灵魂火、熄灭的红石火把、静止水和岩浆、展示传送门、展示活塞部件与燃烧中的熔炉。生存中可用红宝石和四肢乱晃史蒂夫交换随机遗物。普通火和灵魂火都可按盔甲形状合成旧式锁链装备。
