# 愚人节内容与箭袋

这里记录模组中的做法。土豆建筑和薯巨头另见[毒马铃薯地区](./poisonous-potato.md)。

## 黑曜石船

五块**旧黑曜石**按普通船的形状摆放，中间留空。它只载一人，在水里会下沉，船体耐火。别拿它当渡海船；乘客仍可能受到环境伤害。

## 粉红凋灵、爱之傀儡和钻石鸡

在粉红羊毛上放一个种着虞美人的花盆，拿糖右键花盆，可召出粉红凋灵。继续喂糖，它会长出另外两颗头。粉红凋灵会治疗和促进植物生长，击杀它不会掉下界之星。

爱之傀儡也从一个 T 字开始：四块原版铁块摆成铁傀儡的身体，中间上方放粉红羊毛，再拿雕刻南瓜右键粉红羊毛。留出两臂上下的空位。

钻石鸡有机会替代旧世界自然出现的旧鸡，会掉出钻石或青金石，也可能爆炸。红石虫有机会出现在旧世界的红石线旁，触发点是信号上升，持续供电不会反复刷新。

## 生物奖杯

在旧世界亲手击杀支持的生物，有 **10%** 概率掉奖杯。用自己的箭击杀也算。旧牛羊、经典蜘蛛、红龙、巨人、薯巨头等在名单内；普通原版生物不会因为来到旧世界就自动掉奖杯。

奖杯有草、石、金、钻石、下界合金五档，权重依次为 **100 / 50 / 25 / 5 / 1**。闪光是另外独立的 **1%**。奖杯摆在地上会显示生物模型，右键可听到声音，拆下来再放不会丢掉档位或闪光属性。

## 箭袋和历史外观

Indev 箭袋用四块皮革和一根线制作，三行分别是「线、空、皮革」「皮革、空、皮革」「空、皮革、空」。最多装 **64 支普通箭**。右键打开，放进箭后弓或弩可从里面取用。箭袋不属于愚人节快照，和 Indev 齿轮一起收在旧界遗物里。

本地历史资源包只管外观和音效。没装时模组照样运行；某些土豆生物和旧物品会显示兼容外观。
