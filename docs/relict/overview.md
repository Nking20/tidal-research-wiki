# 旧界残响

**旧界残响（Relict）**是一款以 Minecraft 早期历史和社区传说为主题的探索模组。玩家用旧照片和旧相册进入独立的旧世界，在低矮的地形里寻找旧矿井、村落和神庙，遇见历史生物，并带回旧式材料与遗物。

| 项目 | 信息 |
| --- | --- |
| 文档对应版本 | Relict 0.2.0 当前开发版 |
| Minecraft | Java 版 1.21.1 |
| 加载器 | NeoForge 21.1.219 |
| Java | 21 |
| 模组 ID | `relict` |
| 旧世界维度 | `relict:old_world` |

这些页面按当前开发版编写。较早打包的同版本 JAR 可能还没有经典狼、居民背包等后续内容。
