# 旧界残响

旧界残响（Relict）是一个 Minecraft Java 版探索模组。用旧照片打开相册传送门，可以进入旧世界。在那里能找到旧村庄、砖块金字塔、巨木树林，以及取自 2024 年愚人节快照的毒马铃薯地区。

这份文档对应 **Relict 0.4.7**。需要 Minecraft **1.21.1**、NeoForge **21.1.219** 和 Java **21**。模组 ID 是 `relict`，旧世界的维度 ID 是 `relict:old_world`。

合成和用途在 JEI 里查。鼠标指向物品，默认按 **R** 看怎么做，按 **U** 看能做什么。遇到同名物品，按 **F3 + H** 打开高级提示，区分 `relict:` 和 `minecraft:`。
