# 旧界残响

**旧界残响（Relict）**是一款以 Minecraft 早期历史和社区传说为主题的探索模组。用旧照片与旧相册前往旧世界，在高度只有 128 格的维度中探索村庄、矿井与神庙，遇见历史生物，再把旧式材料、装备和技术遗物带回主世界。

| 项目 | 信息 |
| --- | --- |
| 文档对应版本 | Relict 0.2.0 当前开发版 |
| Minecraft | Java 版 1.21.1 |
| 加载器 | NeoForge 21.1.219 |
| Java | 21 |
| 模组 ID | `relict` |
| 旧世界维度 | `relict:old_world` |

第一次玩可以先在主世界做出照片和两本相册，到旧世界放下回程相册，再从地表木材和旧圆石开始。矿井、旧地牢与两座神殿分别适合找淘气鬼、相机和岁月尘。
