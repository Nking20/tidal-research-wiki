# 遗迹与战利品

旧世界共有 13 种可用 `locate structure` 查找的建筑。旧地牢另按地下地物生成。表中的物资是对应战利品表的代表条目，每个箱子的内容会随机抽取。

## 结构一览

| 结构 | 常见位置 | 值得找什么 | 注册 ID |
| --- | --- | --- | --- |
| 旧村庄 | 平原、沙漠、雪原 | 农田、守卫和铁匠铺。铁匠铺可能有旧铁锭、旧铁镐、钻石和作物。 | `relict:old_village` |
| 废弃矿井 | 平原、沙漠、林地、雪原和雨林的地下 | 木支架、轨道、补给矿车和洞穴蜘蛛刷怪点。矿车有机会开出铁镐、钻石和岁月尘。 | `relict:old_mineshaft` |
| 旧屋 | 平原、森林、白桦林、雪原、雨林 | 面包、种子、火把、铁锭和岁月尘，也可能遇见四肢乱晃史蒂夫。 | `relict:old_house` |
| 破旧屋子 | 与旧屋相同的群系 | 旧式陈设和木船旁的四肢乱晃史蒂夫。 | `relict:abandoned_house` |
| 木顶农舍 | 平原、森林、白桦林 | 住客与农田。补给可能有种子、面包、钓鱼竿。 | `relict:timber_farmhouse` |
| 石砌田园小屋 | 平原、森林、白桦林 | 住客与农田。补给可能有马铃薯、胡萝卜、铁镐。 | `relict:stone_farmhouse` |
| 幽居小屋 | 平原、森林、白桦林 | 一至两名黑面史蒂夫，补给包括熟肉、面包、旧煤或铁锭。 | `relict:shadow_lodge` |
| 沙漠神殿 | 旧沙漠 | 地下宝箱可能有钻石、绿宝石、铁金锭和岁月尘。 | `relict:old_desert_temple` |
| 丛林神庙 | 经典丛林 | 发射器和拉杆机关，宝箱可能有马具、马铠、矿物和岁月尘。 | `relict:classic_jungle_temple` |
| 旧要塞 | 地下环状分布，优先选旧平原附近 | 石砖通道、图书馆、末地传送门房间。走廊箱可能有钻石，图书馆箱有书、纸和指南针。 | `relict:old_stronghold` |
| 砖块金字塔 | 多数旧界群系，沿固定网格寻找 | 砖砌阶梯地标。网格候选位置与世界种子无关。 | `relict:brick_pyramid` |
| 石塔 | 平原、沙漠、森林、白桦林、雪原、雨林 | 从开阔地寻找竖直石塔轮廓。 | `relict:old_stone_tower` |
| 苔石坟墓 | 与旧屋相同的群系 | 小型地表遗迹，在低视野或植被密集处容易错过。 | `relict:old_grave` |

木顶农舍和石砌田园小屋共用一组生成位置。群系、地形和附近的其他结构都能影响建筑是否生成。结构集的间距是候选网格设置，例如沙漠神殿为 23 区块、丛林神庙为 26 区块、农舍为 15 区块。

## 机关遗迹怎么进

**沙漠神殿。** 从地面井口沿墙挖阶梯，绕过底部中央的压力板。到达箱子高度后可以先拆除压力板和下方 TNT，再开箱。直接落到井底中央可能引爆整间藏宝室。

**丛林神庙。** 进入地下通道后留意低处绊线和发射器。可以先拆掉绊线，再去找箱子；另一处箱子藏在三拉杆机关后。到访需要进入神庙范围，找对建筑就能开始探索进度。

**废弃矿井。** 用火把标记进来的岔路，注意蜘蛛网和洞穴蜘蛛刷怪点。想找淘气鬼时带上煤和火把，详情见[淘气鬼的互动规则](./mobs.md#淘气鬼的详细规则)。

**幽居小屋。** 先从门窗观察住客和入口。黑面史蒂夫会主动攻击并在受伤时吃东西。小屋有两名住客时，需要留意同时靠近的第二个目标。

## 旧地牢

旧地牢有旧式刷怪笼和两个补给箱。每箱独立有 15% 概率出现 PE 相机、25% 概率出现 1～3 份岁月尘。寻找时可留意地下苔石房间与集中出现的怪物声。相机使用方法见[遗物与历史玩法](./relics.md#pe-相机)。

## 岁月尘的箱子来源

| 箱子或矿车 | 额外抽中岁月尘的概率 |
| --- | ---: |
| 旧屋补给箱 | 20% |
| 旧地牢补给箱 | 25% |
| 旧矿井补给矿车 | 30% |
| 沙漠神殿或丛林神庙宝箱 | 40% |

还可以从[旧界矿石和淘气鬼](./conversion.md#获得岁月尘)补充岁月尘。需要用命令定位时，参照[群系与结构定位指令](./old-world.md#用指令定位)。
