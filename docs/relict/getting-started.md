# 进入旧世界

## 做照片和相册

- **旧照片**：纸、墨囊和末影珍珠各一个，无序合成。也可以用四张照片残片排成 2×2。残片可从[淘气鬼](./mobs.md#淘气鬼)处获得。
- **旧相册**：中间放书，上、左、右各放一块旧木板，书下放一块旧玻璃板。旧玻璃板由六块旧玻璃合成。认不出同名材料时，按 **F3 + H** 看物品 ID。

## 开门

1. 放下相册，留出上方两格空气。
2. 拿旧照片右键相册。相册上方会出现一格宽、两格高的入口，照片不会消耗。
3. 人走进门才会传送。加载时站在门里，传送会在旧世界相同的 X/Z 附近寻找安全落点。

**这扇门是单向的。** 在旧世界放相册不会开回主世界的门。出发前带够食物、工具和照明；落地后可放床设重生点。拆掉相册会关闭入口。

## 卡在门口时

| 现象 | 怎么办 |
| --- | --- |
| 提示清空相册上方 | 搬开上面两格的方块。开门不会替你拆掉它们。 |
| 提示没有安全落点 | 换个坐标放相册。旧世界同一位置可能是海、洞壁或危险地形。 |
| 一直显示寻找落点 | 留在门里等区块加载；超时后可重新进入。迈出门会取消这次传送。 |

先在地表找旧原木和旧圆石。想找田、补给箱或地下矿道，可以从[旧村庄与矿井](./structures.md)开始。
