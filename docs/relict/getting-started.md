# 开局与往返

## 制作旧照片和旧相册

旧照片 `relict:old_photograph` 可以用一张纸、一个墨囊和一颗末影珍珠无序合成，也可以把四张照片残片排成 2×2 合成。照片残片是[淘气鬼](./mobs.md#淘气鬼)的互动奖励之一。

旧相册 `relict:old_album` 需要三块木板、一本书和一块玻璃板。木板接受木板标签中的材料。

```text
空   木板  空
木板 书    木板
空   玻璃板 空
```

## 进入与返回

1. 在主世界放置旧相册，手持旧照片右键相册。
2. 等待目标区块就绪。旧世界以你使用相册时的水平位置为中心，向周围最多 8 格寻找安全落点。
3. 要返回主世界，在旧世界再次用旧照片右键一册已放置的旧相册。第一次出发前可以多带一本，也可以带上制作相册的材料。

照片可重复使用。成功往返后有 1 秒冷却。等待时请留在相册附近。目标区块超时、找不到安全落点或中途离开时，传送会取消。收到提示后可换一个位置重试。

## 第一次探索

获得旧照片后按 **L** 查看「旧世界」进度页。沿着进度探索矿井、村庄和遗迹，或先在地表采集木材与石料。旧世界的铁矿、金矿和钻石矿各有自己的材料链，适合在旧界就地补充工具。

## 出发前带什么

- **往返物品**：旧照片和备用旧相册。可以把第一本留在主世界，在旧世界入口附近放第二本。
- **照明与补给**：火把、食物、常用镐和垫脚方块。探索矿井时额外带煤，遇到淘气鬼就可以建立信任。
- **记下入口**：第一次到达后记下维度坐标，在附近放一个醒目标记。每次传送都根据当次交互的位置寻找落点，可以用这点把出口设在方便补给的区域。

## 传送失败时怎么办

| 现象 | 可以尝试 |
| --- | --- |
| 等待后提示目标区块未准备好 | 留在相册旁再试一次。一次请求最多等待 100 游戏刻，约 5 秒。 |
| 提示找不到安全落点 | 将相册移到开阔区域。系统先在目标附近上下 32 格内搜索，随后还会尝试地表。 |
| 等待中移动后取消 | 在交互点 8 格以内等到提示或传送完成。 |
| 到达后短时间内无法立刻返回 | 成功传送后等约 1 秒，再用照片右键相册。 |

相册路线连接主世界和旧世界。第一次到达后，可按[进度路线](./progression.md)准备旧石器，也可以直接查[遗迹位置和战利品](./structures.md)。
