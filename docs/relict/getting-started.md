# 进入旧世界

## 准备照片和相册

第一次出发，在主世界就能凑齐照片和相册。照着 JEI 做即可。[淘气鬼](./mobs.md#淘气鬼)也可能给照片残片，可以凑成照片。

## 开门

1. 在旧世界以外放下相册，左右两边和上方留空。连相册在内，整扇门占 **3 格宽、5 格高**。
2. 拿照片右键相册。两侧和顶部会出现圆石，相册正上方两格打开传送门。照片会留在手上。
3. 走进门后到达旧世界的配对门。那边的门框用旧圆石，优先在相近的 X/Z 坐标找安全地面，找不到时尝试在对应 X/Z 搭平台。

回程走进配对门即可，出口在来时的维度和相册门附近。在旧世界随手放一本新相册，连不上原来的门。拆掉相册会关闭这一侧的入口。

## 卡在门口时

| 现象 | 怎么办 |
| --- | --- |
| 提示腾出门框空间 | 搬开相册上方和两侧的障碍物，已有的圆石门框可以留着。 |
| 提示没有安全落点 | 检查另一端相册门附近有没有被堵住。第一次开门遇到这个提示，可以换个坐标放相册。 |
| 进门后没有立刻传送 | 在门里等目标区块加载。走出来会取消当前传送，超时后可以重新进门。 |

先在地表找旧原木和旧圆石。想找田、补给箱或地下矿道，可以从[旧村庄与矿井](./structures.md)开始。
