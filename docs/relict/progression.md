# 进度路线

获得旧照片或来到旧世界后，可在原版进度界面（默认 **L**）切换到「旧世界」页签。进度共有 42 项。下表列的是实际触发条件，最右侧是定义的经验奖励。前置列表示进度树上的父节点。

## 推荐顺序

1. 先做照片与相册，进入旧世界并建立回程点。落地后采木和旧圆石，准备石镐、石斧、石剑。
2. 做出旧铁镐，沿矿井和地牢找矿石、淘气鬼和 PE 相机。想一次完成多项收集进度，可以留存一份岁月尘、一块红宝石块和两种金苹果。
3. 从村庄开始记录遗迹路线，再前往矿井、两座神庙与幽居小屋。去丛林神庙时也可以收集丛林原木、树叶、树苗，另去雨林完成群系进度。
4. 收尾时保留一枚下界反应核用于「留下历史的人」。想完成「反应开始」，在反应核运转时再和它交互。
