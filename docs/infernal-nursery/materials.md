# 炼狱饲料与材料用途

## 饲料

以下是默认配方，均为无序合成，成品每次为 3 份

| 饲料 | 原料各 1 份 | 效果 |
| --- | --- | --- |
| 菌食饲料 | 诡异菌 + 诡异疣块 + 下界疣 | 菌食性饲料：+150 饱食度 |
| 熔质饲料 | 岩浆膏 + 岩浆块 + 下界疣 | 熔质食性饲料：+150 饱食度 |
| 灵魂基质饲料 | 灵魂土 + 灵魂沙 + 下界疣 | 灵魂基质食性饲料：+150 饱食度 |

菌食饲料对炽足兽与绯壳甲虫通用，可用原料见 JEI

## 原版食物应急

| 样本 | 原版食物 |
| --- | --- |
| 炽足兽 | 喜欢诡异菌，可接受金胡萝卜和诡异疣块 |
| 岩浆怪 | 岩浆块默认 +65 饱食度，可接受岩浆膏 |
| 霜烬螈 | 灵魂土 +60，灵魂沙 +35 饱食度 |
| 绯壳甲虫 | 绯红菌 +60，下界疣 +35 饱食度，也可接受绯红疣块 |

对着槽乱投食物可能没有效果或造成不良反馈，不能只看原版玩家是否能吃这个物品

## 产物循环

| 原料 | 配方或用途 |
| --- | --- |
| 炽足绒 ×1 | 线 ×2，或用于保温护理、隔热衬层 |
| 高纯熔胶 ×1 + 诡异菌 ×1 | 活性胶质 ×1 |
| 甲质碎屑 ×1 + 灵魂土 ×1 + 骨粉 ×1 | 矿化基质 ×1 |
| 甲壳碎片 ×4 | 骨粉 ×3 |
| 冷凝腺液 | 冷凝剂相关加工与温和复苏剂配方 |
| 完整绯壳 | 完美蜕壳产物，具体装备与材料用途查 JEI |

岩浆膏是岩浆怪的概率副产，高纯熔胶是主产物，活性熔胶是采样或分裂得到的前体，三者不能互相混称

## 和核心材料衔接

炼狱通过共用材料标签接入部分调律、培养与复原配方，高纯熔胶可被对应活性胶材料标签接受

共用不等于所有配方都直接接受替代品，先看 JEI 原料是否轮换显示该材料

核心的皮革、消化器、生物液等循环见[潮汐材料说明](../tidal-nursery/materials.md)
