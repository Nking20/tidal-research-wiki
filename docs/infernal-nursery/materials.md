# 炼狱饲料、食品与材料用途

## 饲料

以下是默认配方，均为无序合成，成品每次为 3 份

| 饲料 | 原料各 1 份 | 效果 |
| --- | --- | --- |
| 菌食饲料 | 诡异菌 + 诡异疣块 + 下界疣 | 菌食性饲料：+150 饱食度 |
| 菌食饲料 | 绯红菌 + 下界疣块 + 下界疣 | 菌食性饲料：+150 饱食度 |
| 菌食饲料 | 灰烬菌 + 灰烬疣块 + 下界疣 | 菌食性饲料：+150 饱食度 |
| 熔质饲料 | 岩浆膏 + 岩浆块 + 下界疣 | 熔质食性饲料：+150 饱食度 |
| 灵魂基质饲料 | 灵魂土 + 灵魂沙 + 下界疣 | 灵魂基质食性饲料：+150 饱食度 |

三条菌食配方均产出同一种 `infernalnursery:fungus_feed`，供炽足兽与绯壳甲虫使用

菌食性样本喜欢绯红菌、诡异菌、灰烬菌、菌食饲料和菌饼，原料生长见[菌丛种植](./fungi.md)

## 原版食物应急

| 样本 | 原版食物 |
| --- | --- |
| 炽足兽 | 下界菌类和菌饼为菌食选择，也可接受金胡萝卜和诡异疣块 |
| 岩浆怪 | 岩浆块默认 +65 饱食度，可接受岩浆膏 |
| 霜烬螈 | 灵魂土 +60，灵魂沙 +35 饱食度 |
| 绯壳甲虫 | 下界菌类和菌饼为菌食选择，下界疣默认 +35 饱食度，也可接受绯红疣块 |

对着槽乱投食物可能没有效果或造成不良反馈，不能只看原版玩家是否能吃这个物品

## 玩家食品

| 食品 | 无序配方 | 饥饿恢复 | 饱和度系数 | 堆叠 |
| --- | --- | ---: | ---: | ---: |
| 菌饼 | 任意下界菌 ×1 + 下界纤维植物 ×2 | 4 | 0.3 | 64 |
| 下界菌煲 | 任意下界菌 ×3 + 碗 ×1 | 6 | 0.6 | 1 |

每次合成 1 份，任意下界菌包含绯红菌、诡异菌和灰烬菌，各菌类位可以混用

纤维植物位可使用下界苗、绯红菌索或诡异菌索，两个纤维位可以分别选择

菌饼食用有 5% 概率获得 6 秒反胃 I；下界菌煲食用后返还碗

## 产物循环

| 原料 | 配方或用途 |
| --- | --- |
| 炽足绒 ×1 | 线 ×2，或用于保温护理、隔热衬层、滑翔伞制作与修理 |
| 高纯熔胶 ×1 + 诡异菌 ×1 | 活性胶质 ×1 |
| 甲质碎屑 | 与灵魂土、骨粉各 1 份合成矿化基质 ×1，或用于滑翔伞灵巧型调律 |
| 甲壳碎片 ×4 | 骨粉 ×3 |
| 冷凝腺液 | 瓶装冷凝腺液、温和复苏剂，以及滑翔伞远航型调律 |
| 完整绯壳 | 完美蜕壳成果，可收集保存 |

岩浆膏是岩浆怪的概率副产，高纯熔胶是主产物，活性熔胶是采样或分裂得到的前体，三者不能互相混称

滑翔伞各路线的耗材和数量见[旅行与滑翔](./travel.md#三条互斥调律)

## 和核心材料衔接

炼狱通过共用材料标签接入部分调律、培养与复原配方，高纯熔胶可被对应活性胶材料标签接受

共用不等于所有配方都直接接受替代品，先看 JEI 原料是否轮换显示该材料

核心的皮革、消化器、生物液等循环见[潮汐材料说明](../tidal-nursery/materials.md)
