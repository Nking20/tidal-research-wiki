# 炼狱安装、配置与兼容

## 安装关系

本节使用 **炼狱培育 0.4.5-alpha + 潮汐培育 1.0.8-alpha** 的配套开发版本，运行环境为 Minecraft 1.21.1、NeoForge 21.1.219 和 Java 21

炼狱依赖潮汐培育与 **GeckoLib 4.9.3，版本范围低于 5**，按同一批次文件准备客户端与服务端

客户端与服务端安装相容版本，炼狱与潮汐共用基因档案系统

## 配置

温控、食物、分裂与蜕壳参数使用服务端配置

- 单人：`saves/<世界>/serverconfig/infernalnursery-server.toml`
- 独立服务器：`<世界目录>/serverconfig/infernalnursery-server.toml`
- 新世界默认值可通过整合包的 `defaultconfigs` 准备

配置以服务端世界为准，默认环境扫描约 10 秒，温标为 -100～+100

灰烬菌、角砾岩和遗迹分布使用数据包世界生成文件；猪灵额外回报使用战利品表，入口见[探索与交易](./exploration.md)

## 基因拓展

基础两组为体型 / 韧性、代谢 / 产能，拓展组为耐温 / 炼狱环境亲和

四种物种使用 `infernalnursery:thermal` 拓展，采集、记录、档案、删除和重构由核心处理，档案组合按物种分别保存

耐温调节冷热边界，环境亲和调节自然与人工温控响应，具体效果在熔育槽详情查看

## 保存与兼容

熔育槽保存样本、介质和事件状态，搬运后按保存数据恢复

菌食饲料的注册 ID 为 `infernalnursery:fungus_feed`，菌饼和下界菌煲接受的菌类由 `infernalnursery:nether_fungi` 标签提供

升级前备份世界，无法识别的数据保留原件并提供日志排查，含有炼狱注册内容的世界需要保留模组

## 排查

| 现象 | 检查 |
| --- | --- |
| 温度不变 | 等待环境扫描，悬停温度计查看来源 |
| 配件无法放入 | 加热和制冷互斥，按槽位要求安装 |
| 霜烬螈休眠 | 按显示原因处理温度或饥饿 |
| 梳毛或凝露暂停 | 阶段、恢复状态、温度、健康与饱食 |
| 分裂暂停 | 健康至少 80、饱食至少 70，并处理护理需求 |
| 蜕壳质量偏低 | 检查本轮健康、饱食、温度与蜕缝清洁 |
| 无法采样 | 核对生物尺寸、临时状态和已采样提示 |

报告问题时提供两个模组版本、复现步骤和日志
