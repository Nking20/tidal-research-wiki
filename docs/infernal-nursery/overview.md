# 炼狱培育

炼狱培育是潮汐培育的下界扩展，将采样、成长与基因收藏接入熔育槽，培养重点由水量和光照转向温度与介质

本节对应 **Infernal Nursery 0.4.5-alpha / Tidal Nursery 1.0.8-alpha / Minecraft 1.21.1 NeoForge**，依赖和安装见[兼容说明](./compatibility.md)

除了培养四种样本，还可以培育菌丛、寻找灰烬菌并催生巨菌、加工菌木和火山角砾岩、制作菌食料理，以及使用灰烬菌船和菌膜滑翔伞旅行

## 第一次培养

1. 在潮汐培育中取得精细采样网，制作组织采样器
2. 找到可采样生物，满足它的采样状态后右键取得前体
3. 制作熔育槽，放入前体
4. 查看温度计，按样本需要加介质或温控配件
5. 显形后按食性喂食、处理护理，等待成年收获
6. 用空白基因载体对成熟样本提取记录，加入核心基因档案

按样本需要选择温控介质和配件

## 四种样本

| 物种 | 培养方向 |
| --- | --- |
| 炽足兽 | 菌食、炽足绒 |
| 岩浆怪 | 熔质食性、高纯熔胶与分裂 |
| 霜烬螈 | 灵魂基质食性、低温凝露 |
| 绯壳甲虫 | 菌食、甲壳与蜕壳 |

温标为 -100～+100，具体温区、介质与调温方式集中在[熔育槽](./molten-vat.md)页面，温度计可显示来源与建议
