# 炼狱培育

炼狱培育是潮汐培育的下界扩展，将采样、成长与基因收藏接入熔育槽，培养重点由水量和光照转向温度与介质

本文对应 **Infernal Nursery 0.4.4-alpha**，依赖 **Tidal Nursery 1.0.4-alpha 或相容版本**，目标为 Minecraft 1.21.1 NeoForge，按 2026-10-17 本地代码整理

## 第一次培养

1. 在潮汐培育中取得精细采样网，制作组织采样器
2. 找到可采样生物，满足它的采样状态后右键取得前体
3. 制作熔育槽，放入前体
4. 查看温度计，按样本需要加介质或温控配件
5. 显形后按食性喂食、处理护理，等待成年收获
6. 用空白基因载体对成熟样本提取记录，加入核心基因档案

**熔育槽新放置时为空，不自动带水或岩浆**，空槽也能作为温控起点，介质按需要加入

## 四种样本

| 物种 | 培养方向 | 默认最佳温区 |
| --- | --- | --- |
| 炽足兽 | 菌食、炽足绒 | +55～+75 |
| 岩浆怪 | 熔质食性、高纯熔胶与分裂 | +75～+95 |
| 霜烬螈 | 灵魂基质食性、低温凝露 | -55～-25 |
| 绯壳甲虫 | 菌食、甲壳与蜕壳 | +30～+50 |

温标是模组内部的 -100～+100，**不是摄氏度**，表中最佳区间是物种默认值，正常可培养范围更宽，具体看温度计
