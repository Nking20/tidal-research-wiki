# 熔育槽、温度与护理

## 介质与容量

熔育槽容量 **4000 mB**，新物品放下时为空，搬运与读档按已保存介质恢复

| 介质 | 主要用途 |
| --- | --- |
| 水 | 降温 |
| 岩浆 | 升温 |
| 细雪 | 低温培养 |
| 空槽 | 仅用群系、基底、热源和配件调温 |

水、岩浆和细雪不会因正常培养持续消耗，换种类前先取空，细雪按桶装固体保存，不能把它当作任意流体混入管道

槽里有多少介质会影响温度修正，不必一开始就灌满，水不是所有物种的必需品

## 怎样调温

温度由群系、维度、介质量、附近热源、槽底方块、隔热与主动温控共同计算，环境亲和会改变部分来源的响应

**悬停温度计查看来源明细与建议**，先看是哪一项过高或过低，再增减材料

| 手段 | 默认基础方向 |
| --- | --- |
| 岩浆介质 | 升温，满槽基础 +30 |
| 水介质 | 降温，满槽基础 -30 |
| 岩浆块基底 | +10 |
| 冰 / 浮冰 / 蓝冰基底 | -5 / -10 / -15 |
| 主动加热组件 | 基础 +15 |
| 主动冷却组件 | 基础 -15 |
| 强化加热 / 制冷元件 | 对应普通元件的两倍基础效果 |
| 隔热衬层 | 减轻环境低温影响 |

表中为来源基础值，**不是最终读数承诺**，例如同一槽在主世界与灵魂沙峡谷的读数会不同

环境扫描有间隔，默认约 10 秒，不要刚换底座就立即重复投入材料

## 四种最佳温区

| 样本 | 最佳温区 | 处理方向 |
| --- | --- | --- |
| 炽足兽 | +55～+75 | 适当升温，避免极冷与过热 |
| 岩浆怪 | +75～+95 | 较高温，保持良好健康与饱食 |
| 霜烬螈 | -55～-25 | 低温环境、冷介质和制冷配件 |
| 绯壳甲虫 | +30～+50 | 温暖即可，不必照搬岩浆怪配置 |

耐温基因扩展冷热边界，最佳温区不随它任意平移，处于“正常”可培养但未必达到“最佳”效率

## 配件和护理

熔育槽有两个配件槽，加热与制冷不能同时安装，同类只取最高等级，不通过装两件叠加等级

还支持部分共用培养配件，环境槽可使用防污衬片，实际可放物品以槽位与 JEI 为准

| 需求 | 处理 |
| --- | --- |
| 熔渣、凝壳、污物等清洁需求 | 清洁刷 |
| 炽足兽保温护理 | 炽足绒 |
| 岩浆怪熔质补充 | 高纯熔胶 |
| 缺少食物 | 按菌食、熔质或灵魂基质食性喂食 |
| 严重低温或过热 | 根据温度来源调整介质、基底与配件 |

休眠时先处理原因，例如严重饥饿先喂食，再等待恢复，休眠展示不会继续正常游动

## 收获、封存与基因

普通收获、留存和封存与培育皿共用机制，用封存瓶按 **潜行键 + 右键**取出样本

空白基因载体可直接右键有成熟样本的槽提取记录，之后在基因育成槽中导入、选择并重构同物种前体

熔育槽详情中显示完整基因效果，Jade 只作状态与炫彩概览，具体事件条件见[样本与特殊事件](./specimens.md)
