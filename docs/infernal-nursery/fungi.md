# 菌丛、灰烬菌与巨型菌

菌类可以在粉碎下界岩上培育为可重复采收的菌丛；灰烬菌也可以在灰烬菌岩上催生巨型菌，取得菌木与菌冠材料

## 制作菌床

1. 手持镐，对下界岩、绯红菌岩或诡异菌岩右键
2. 方块变为粉碎下界岩，消耗工具 1 点耐久
3. 保持上方为空，用绯红菌、诡异菌或灰烬菌右键粉碎下界岩顶面
4. 消耗 1 个菌，种出相应菌丛

## 菌丛成长与采收

菌丛具有 AGE 0～3 四个阶段，通过随机刻成长，低光照下成长机会较高

成熟后空手右键或使用收获手套采收，保留菌床与植株，回到 AGE 0 继续生长

三种菌丛分别产出对应的绯红菌、诡异菌和灰烬菌，具体掉落可在 JEI 或实际收获中查看

菌类用于菌食饲料、菌饼与下界菌煲，配方见[材料与食品](./materials.md)

## 寻找灰烬菌

灰烬菌、灰烬菌岩和巨型灰烬菌自然生成于原版玄武岩三角洲，巨菌周围可找到局部菌岩和小型菌

灰烬菌可以挖取、移植和放入花盆；灰烬菌及菌岩也可能通过[猪灵以物易物](./exploration.md#猪灵以物易物)取得

## 灰烬菌岩

灰烬菌岩是灰烬菌巨型化的生长基底

- 使用正确工具并带精准采集可保留菌岩
- 普通挖掘掉落黑石
- 上方被足以遮蔽的方块覆盖后，会通过随机刻退化为黑石

栽培时保持顶部空间，留意菌冠所需范围

## 催生巨型灰烬菌

1. 将灰烬菌种在灰烬菌岩上
2. 在周围和上方预留足够空间
3. 使用骨粉，单次成功判定概率约为 40%
4. 成功后生成连续弯折的菌柄、侧枝与宽扁菌冠

巨菌通常高 7～11 格，主冠约宽 5～9 格，包含单冠、双冠和明显偏向一侧的轮廓

空间不足时不能形成完整巨菌，普通随机刻用于菌丛成长，巨型化通过灰烬菌岩上的骨粉操作触发

## 砍伐与利用

菌柄、菌丝体可用斧头去皮并加工木板，菌冠提供灰烬疣块，部分巨菌上可找到浅蓝色烬源体

灰烬全方块具有铁级采集要求，菌柄、菌冠和菌岩分别使用对应种类的工具，见[采集工具表](./building.md#采集工具)；去皮通过斧头右键操作

木板、门、告示牌及其他建材见[灰烬菌木与火山角砾岩](./building.md)
