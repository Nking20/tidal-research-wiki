# 灰烬菌木与火山角砾岩

建筑材料集中在「炼狱培育建筑方块」创造栏，常用配方可在工作台或切石机查看

## 灰烬菌木

| 材料 | 获取与加工 |
| --- | --- |
| 灰烬菌柄 | 砍伐巨型灰烬菌 |
| 去皮灰烬菌柄 | 用斧头右键菌柄 |
| 灰烬菌丝体 | 4 个菌柄按 2×2 合成 3 个 |
| 去皮灰烬菌丝体 | 4 个去皮菌柄按 2×2 合成 3 个，或对菌丝体使用斧头 |
| 灰烬木板 | 每个菌柄、去皮菌柄、菌丝体或去皮菌丝体加工 4 块 |
| 灰烬疣块 | 巨型菌冠 |
| 烬源体 | 巨型菌上的浅蓝色光源，亮度 15 |

菌木建筑包括楼梯、台阶、栅栏、栅栏门、门、活板门、按钮、压力板、告示牌和悬挂式告示牌，采用对应的原版木材配方形式

灰烬菌木建筑不燃烧，按钮、压力板、门和栅栏门保留相应交互与红石功能

灰烬菌的获取和催生见[菌丛与灰烬菌](./fungi.md)，灰烬菌船见[旅行与滑翔](./travel.md)

## 采集工具

下列灰烬完整方块需要铁级或更高的对应工具才能正常取得掉落

| 方块 | 工具 |
| --- | --- |
| 灰烬菌柄、去皮菌柄、菌丝体、去皮菌丝体、灰烬木板 | 铁斧或更高级斧具 |
| 灰烬菌岩 | 铁镐或更高级镐具，精准采集可保留菌岩 |
| 灰烬疣块、烬源体 | 铁锄或更高级锄具 |

## 火山角砾岩

下界的部分玄武岩会以矿脉方式生成火山角砾岩，手工合成使用下面的 2×2 交叉配方，产出 4 块

```text
玄武岩       粉碎下界岩
粉碎下界岩   玄武岩
```

粉碎下界岩的制作见[菌床](./fungi.md#制作菌床)

## 四组外观

| 系列 | 工作台配方 | 形式 |
| --- | --- | --- |
| 火山角砾岩 | 玄武岩 ×2 + 粉碎下界岩 ×2，交叉摆放得到 4 块 | 方块、楼梯、台阶、墙 |
| 磨制火山角砾岩 | 4 块普通角砾岩按 2×2 得到 4 块 | 方块、楼梯、台阶、墙 |
| 火山角砾岩砖 | 4 块磨制角砾岩按 2×2 得到 4 块 | 方块、楼梯、台阶、墙 |
| 錾制火山角砾岩 | 两个角砾岩砖台阶上下摆放得到 1 块 | 完整雕刻方块 |

合计 13 种建筑方块

楼梯采用 6 块材料的原版阶梯配方，产出 4 个；台阶用一横排 3 块材料产出 6 个；墙用两横排 6 块材料产出 6 面

切石机可以沿系列加工完整砖块、楼梯、台阶与墙，每个完整方块可切出 1 个楼梯、2 个台阶或 1 面墙；可用转换以 JEI 为准

磨制材质具有随机纹理变化，同一注册方块可显示不同石纹
