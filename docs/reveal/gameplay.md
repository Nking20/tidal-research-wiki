# 辑录与揭秘基础玩法

辑录与揭秘的核心循环很简单：玩家获得辑录册和揭秘集，收集对应物品，把物品放入揭秘集后解锁一条对应来源的辑录，再回到辑录册中查看。

## 谱系物品

| 物品 | 用途 |
| --- | --- |
| 揭秘集 | 投入物品并解锁辑录 |
| 辑录册 | 查看来源、进度、黑影和已解锁内容 |
| 辑录页 | 直接打开单条内容 |

默认配置下，玩家首次进入世界会获得辑录册和揭秘集。服务器或整合包可以关闭这个规则，改成任务奖励、合成、商店或战利品获取。

## 解锁方式

玩家把物品放入揭秘集后，模组会根据 `config/reveal.json` 中的 `recipes` 判断目标来源。

例如：

- 纸可以解锁“原版小提示”。
- 书和荧光墨囊可以解锁“未知语言”。
- 苦力怕掉落的唱片可以解锁“苦力怕的秘密”。

如果该来源还有未解锁内容，揭秘集会解锁一条辑录。已经解锁的内容可以在辑录册中反复查看。

## 解锁策略

每个来源可以配置不同的解锁策略：

| 策略 | 说明 |
| --- | --- |
| `pool` | 按 `order` 阶段推进，同一阶段内按权重抽取 |
| `random` | 在当前来源的未解锁内容中按权重随机抽取 |

玩家界面不会直接显示“线性”或“随机”，只会看到当前来源中已经解锁了多少条，还剩多少条。

## 辑录册界面

辑录册会显示来源、来源图标、解锁进度和每条辑录的图标状态。

- 未解锁条目显示黑影。
- 已解锁条目显示对应物品图标。
- 鼠标悬停来源图标时，会显示该来源的揭秘配方提示。
- 进入具体辑录后，可以翻页、返回辑录册，也可以跳到同来源的上一张或下一张。

## UI 风格

模组提供两种书页风格：

| 风格 | 说明 |
| --- | --- |
| `book_clean` | 更干净的纸面，适合长期阅读 |
| `book_old` | 旧书风格，保留书脊和旧纸质感 |

玩家可以在游戏内通过 UI 按钮切换，也可以由配置文件指定默认风格。
