# 玩家玩法

## 操作速查

| 操作 | 结果 |
| --- | --- |
| 手持辑录册右键 | 同步玩家与背包中辑录册的进度，然后打开辑录目录。 |
| 手持辑录册 Shift + 右键 | 打开“辑录揭秘”界面。 |
| 手持辑录页右键 | 直接阅读该辑录页记录的条目。 |
| 手持旧版揭秘集右键 | 打开“辑录揭秘”界面；该物品仅用于旧存档兼容。 |
| 在目录或阅读页点击 `X` | 关闭界面。 |
| 按物品栏键（默认 `E`） | 在目录中关闭界面；从目录进入阅读页时返回目录。 |
| 按空格 | 在新版目录中返回类别列表；在阅读页中返回目录。 |

## 获得辑录册

默认配置下，每名玩家第一次登录该世界时会获得一本 `reveal:index_book`（辑录册）。这里只发放辑录册，不会发放旧版揭秘集。

发放状态会记录在玩家数据中，并不是每次登录都检查背包补发：

- 辑录册丢失后不会自动再给一本。
- 玩家第一次登录时若关闭了自动发放，之后再开启也不会给这名玩家补发。
- 当前版本没有内置的辑录册合成配方。

管理员可以直接给予：

```mcfunction
/give @s reveal:index_book
```

整合包也可以关闭 `give_index_book_on_first_join`，改用任务、商店、战利品表或自定义合成配方发放。

## 第一次打开辑录册

手持辑录册普通右键会打开目录。打开前，模组会先合并当前玩家、手中辑录册以及背包/副手中其他辑录册的解锁记录。

默认配置的 `vanilla_tips.initial_unlocked` 为 `3`，所以玩家第一次普通右键打开辑录册时，会自动获得该类别排序最前的 3 条记录。隐藏类别不会通过 `initial_unlocked` 自动解锁。

## 浏览目录

新版 `book_clean` 界面先显示类别列表：

1. 点击一个类别进入其条目列表。
2. 点击已解锁条目进入阅读页。
3. 点击未解锁条目只会播放拒绝音效，不会显示正文。
4. 使用左右翻页按钮浏览更多类别或条目。
5. 使用返回按钮或空格回到类别列表。

界面中的“样式”按钮可以在 `book_clean` 与 `book_old` 之间切换。旧样式把类别和条目排列在同一个目录中，不使用单独的类别详情层。

被标记为 `hidden` 的类别，在玩家尚未解锁该类别任何条目时不会出现在目录里；获得第一条记录后才会显示。

## 阅读条目

从目录点击已解锁条目后：

- 使用“上一页 / 下一页”阅读同一条目的多页内容。
- 使用“上一篇 / 下一篇”切换到同类别相邻的已解锁条目。
- 使用“返回辑录册”按钮、空格或物品栏键返回刚才的目录位置。
- 点击样式按钮可切换书页外观。

如果是手持辑录页直接右键打开，阅读页没有目录返回状态；此时只能在该条目内翻页或关闭界面。

## 使用线索揭秘

手持辑录册 **Shift + 右键** 会打开“辑录揭秘”界面。旧版兼容物品 `reveal:reveal_codex` 普通右键也会打开同一界面。

操作步骤：

1. 把一件或两件线索物品放入 **线索 A / 线索 B**。
2. 物品放入后，界面会显示“可揭秘”“无法揭秘”“已经完成”等预览状态。
3. 点击“揭秘”按钮。
4. 匹配成功后，模组从目标类别中选出一条尚未解锁的记录。
5. 成功使用的线索被消耗，记录写入玩家数据与背包中的辑录册，并按配置发放经验或辑录页。

单物品组合可放在任意一个线索槽，另一个槽保持为空。双物品组合不区分 A、B 顺序。可以用 Shift + 点击把背包物品快速移入线索槽。

关闭界面时，仍留在线索槽中的物品会退回玩家背包；背包放不下时会掉落到玩家附近。

### 默认线索组合

| 线索物品 | 目标类别 |
| --- | --- |
| 纸 | `vanilla_tips` |
| 哭泣的黑曜石 + 墨囊 | `omitted_note` |
| 书 + 荧光墨囊 | `unknown_language` |
| 紫水晶碎片 + 墨囊 | `whisper` |
| 任意 `minecraft:creeper_drop_music_discs` 标签物品 | `creeper_secret` |
| 铁镐 + 面包 | `survival_notes` |
| 已填写的地图 + 回响碎片 | `world_rumors` |

服务器配置可以替换、删除或增加这些组合，实际玩法以服务器的 `config/reveal/reveal.json` 为准。

### 成功、失败与消耗

- 没有匹配配方、目标类别不存在或该类别已经全部完成时，不消耗线索。
- 生存模式成功揭秘时，每个命中的线索槽消耗 1 个物品。
- 创造模式默认不消耗线索；`creative_consumes` 可改变这一规则。
- 默认根经验奖励为 5 点。实际数值按“条目 → 类别 → 根配置”的顺序决定。
- 条目或类别的 `experience_reward` 为 `-1` 时继续继承，为 `0` 时明确不奖励经验。
- `give_story_page_on_unlock` 默认关闭；开启后，每次成功揭秘还会给予对应辑录页。背包已满时辑录页掉落在玩家附近。

类别的解锁策略会影响选中哪一条记录：

| 策略 | 行为 |
| --- | --- |
| `ordered` | 按 `order` 和条目 ID 依次解锁。 |
| `pool` | 只在当前最小 `order` 的一组条目中按 `weight` 抽取。 |
| `random` | 在该类别全部未解锁条目中按 `weight` 抽取。 |

## 辑录页

`reveal:story_page` 保存一个类别 ID 和条目 ID，物品名称会显示对应条目的标题。手持有效辑录页右键，可以不经过目录直接打开该条目。

辑录页本身不会把该记录写入玩家进度；它只是一个可选的实体奖励与直接阅读入口。是否在揭秘成功时发放由 `give_story_page_on_unlock` 控制。

## 旧版揭秘集

`reveal:reveal_codex` 是为旧存档和旧配方保留的兼容物品：

- 右键直接打开揭秘界面。
- 不提供目录和阅读入口。
- 默认首次登录不会发放。
- 新整合包应以 `reveal:index_book` 作为主要入口。

## JEI 联动

安装 JEI 后，Reveal 会注册“辑录揭秘配方”类别：

- 辑录册会显示为该配方类别的用途物品。
- JEI 可查看当前配置中非隐藏类别的线索组合。
- 在揭秘界面查看 JEI 配方时，可以使用配方转移按钮把材料移入两个线索槽。
- 编辑器保存类别或配方后，JEI 中的 Reveal 配方会随之刷新。

隐藏类别的配方不会显示在 JEI 中。

## 进度如何保存和同步

Reveal 同时在玩家数据和辑录册物品中保存解锁记录。

每次普通右键或 Shift + 右键使用辑录册时，模组会合并：

- 当前玩家的解锁进度；
- 手中辑录册的进度；
- 主背包与副手中其他辑录册的进度。

合并后的并集会写回玩家和这些辑录册。成功揭秘时，新记录也会立即写入玩家背包中的全部辑录册。

地面掉落物、箱子、潜影盒或其他容器中的辑录册不会自动参与同步；需要先取回玩家背包，再使用一次辑录册。

## 常见情况

| 现象 | 处理方式 |
| --- | --- |
| Shift + 右键没有打开揭秘界面 | 确认手持的是 `reveal:index_book`，并且潜行状态已经生效。旧版揭秘集无需潜行。 |
| 点击“揭秘”没有结果 | 检查线索是否匹配服务器配置、目标类别是否存在，以及是否还有未解锁条目；管理员可执行 `/reveal doctor`。 |
| 单物品配方无法命中 | 另一个线索槽必须为空；单件线索放在 A 或 B 都可以。 |
| 线索顺序放反 | 双物品组合不区分顺序，无需交换。 |
| 辑录册丢失后没有补发 | 首次发放只执行一次；使用 `/give`、任务或其他整合包获取方式补发。 |
| 已经解锁却在另一本书中看不到 | 把书放进主背包或副手，然后普通右键或 Shift + 右键使用任意辑录册进行同步。 |
| 看不到某个类别 | 该类别可能被设为隐藏，需要先通过揭秘或命令获得其中一条记录。 |
| 成功揭秘但没有辑录页 | `give_story_page_on_unlock` 默认关闭；进度仍然已经保存。 |
| 安装数据包后没有新条目 | 执行 `/reveal export-defaults` 导出尚不存在的条目，再执行 `/reveal reload`。 |
| 想直接维护类别、条目或配方 | 有权限的玩家执行 `/reveal editor`。 |
