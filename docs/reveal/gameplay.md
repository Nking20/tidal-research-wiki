# 玩家玩法

## 操作速查

| 操作 | 结果 |
| --- | --- |
| 点击物品栏底部的辑录册页签 | 打开辑录册。 |
| Shift + 点击物品栏底部的辑录册页签 | 直接进入揭秘界面。 |
| 手持辑录册右键 | 同步进度并打开辑录册。 |
| 手持辑录册 Shift + 右键 | 进入揭秘界面。 |
| 右键已放置的揭秘研究站 | 打开研究站揭秘界面，不需要手持辑录册。 |
| 手持普通辑录页右键 | 直接阅读该页记录的单条辑录。 |
| 手持共享辑录页右键 | 收录其中自己尚未拥有的辑录，并消耗该页。 |
| 手持旧版揭秘集右键 | 进入揭秘界面。 |

Shift 点击、辑录册右上角“揭秘”及旧版揭秘集都属于随身揭秘入口。服务器关闭 `inventory_reveal_enabled` 后，这些入口不再提供材料揭秘，需要使用揭秘研究站；查看辑录册、共享、阅读和背包自动解锁不受影响。

## 获得辑录册

默认配置下，每名玩家第一次进入世界时会获得一本 `reveal:index_book`。这里只发放辑录册，不会发放旧版揭秘集。

首次发放只执行一次：辑录册丢失后不会自动补发；如果玩家第一次进入时服务器关闭了自动发放，之后重新开启也不会给这名玩家补发。当前版本没有内置的辑录册合成配方。

管理员可以直接给予：

```mcfunction
/give @s reveal:index_book
```

整合包可以关闭 `give_index_book_on_first_join`，改用任务、商店、战利品表或自定义配方发放。

## 打开辑录册

玩家不必把辑录册拿在手上。打开物品栏后，底部会出现一个与原版物品栏相连的伸缩页签：

- 点击页签打开辑录册。
- 按住 Shift 点击页签，直接进入揭秘界面。
- 同时安装支持同一底部页签规范的潮汐系列模组时，各模组按钮会并排排列。

手持辑录册普通右键和 Shift + 右键仍然保留。每次打开时，模组会合并玩家数据、主背包和副手中所有辑录册的进度。

默认配置的 `vanilla_tips.initial_unlocked` 为 `3`，玩家第一次打开辑录册时会获得该篇章排序最前的 3 条辑录。隐藏篇章不会通过 `initial_unlocked` 自动解锁。

## 揭秘研究站

将 **讲台 + 书 + 紫水晶碎片** 放入合成栏，无序合成一个 `reveal:research_station`。

放置后右键即可进入材料揭秘界面，不需要插入辑录册，也不受随身揭秘开关限制。研究站和随身入口使用相同的材料规则及玩家进度。

研究站的两个线索槽属于当前打开界面的玩家，不是供多人共用的储物空间。关闭界面时材料退回背包；研究站被破坏或玩家离得太远后，界面不能继续揭秘。

## 目录与阅读

`book_clean` 先显示篇章列表；`book_old` 会把篇章和辑录排列在同一页。右上角“样式”按钮可以在两种外观之间切换。

- 点击篇章进入对应的辑录列表。
- 点击已解锁辑录进入阅读页。
- 未解锁辑录只显示剪影，不能打开正文。
- 新获得但尚未阅读的辑录会显示金色五角星。
- 打开该辑录后即视为已读；返回目录时五角星立即消失。
- 隐藏篇章只有在玩家至少获得其中一条辑录后才会出现。
- 鼠标滚轮和页面两侧按钮均可翻页。

阅读页支持同一辑录内翻页，以及切换到同篇章相邻的已解锁辑录。空格、物品栏键或“返回辑录册”按钮会回到刚才的目录位置。

### 搜索与筛选

目录底部提供搜索栏、状态筛选和篇章筛选，两种书页样式均可使用：

- 搜索匹配辑录标题、篇章显示名和辑录 ID，不区分大小写。
- 状态依次切换为“全部”“未读”“已解锁”“未解锁”。
- 篇章按钮可在全部篇章与指定篇章之间切换，并与搜索、状态筛选同时生效。
- 在搜索栏内右键可清空文字，保留输入焦点和其他筛选条件。
- 阅读后返回目录会保留搜索和筛选；阅读页的相邻辑录切换也遵循当前筛选结果。

## 解锁方式

1.3.0 支持五种解锁条件：

| 类型 | 触发方式 |
| --- | --- |
| `materials` | 在揭秘界面放入一件或两件指定物品并点击“揭秘”。 |
| `inventory_items` | 背包或副手持有指定物品后自动解锁，不消耗物品。 |
| `kill_entity` | 玩家亲自击杀指定生物。 |
| `enter_biome` | 玩家进入指定群系。 |
| `advancement` | 玩家完成指定原版或数据包进度。 |

除材料揭秘外，其余四种均由服务器自动检测，不需要打开揭秘界面。材料、击杀、群系和进度条件每次解锁指定辑录或按篇章策略选取一条；背包持有物品条件可以直接解锁指定辑录，也可以一次解锁整个篇章中尚未获得的正常候选内容。

### 材料揭秘

1. 打开研究站或随身揭秘界面，把一件或两件线索物品放入上方两个槽位。
2. 将鼠标移到放大镜图案或“揭秘”按钮上，查看当前匹配状态。
3. 点击“揭秘”。
4. 成功后写入玩家进度和背包中的辑录册，并按配置发放经验或普通辑录页。

单物品条件可放在任意一个槽位；双物品条件不区分 A、B 顺序。Shift + 点击可从背包快速移入材料。关闭界面时，未使用的物品会退回背包，背包已满时掉落在玩家附近。

每条材料解锁方式都能单独设置 `consume_inputs`：

- `true`：生存模式成功揭秘后，每个命中的槽位消耗 1 个物品。
- `false`：成功揭秘后保留材料。
- 创造模式是否消耗还受根配置 `creative_consumes` 控制。
- 条件未命中、目标不存在或目标已经完成时不会消耗材料。

### 默认材料条件

| 材料 | 目标 |
| --- | --- |
| 纸 | `vanilla_tips` 篇章 |
| 哭泣的黑曜石 + 墨囊 | `omitted_note` 篇章 |
| 书 + 荧光墨囊 | `unknown_language` 篇章 |
| 紫水晶碎片 + 墨囊 | `whisper` 篇章 |
| 任意 `minecraft:creeper_drop_music_discs` 标签物品 | `creeper_secret` 篇章 |
| 铁镐 + 面包 | `survival_notes` 篇章 |
| 已填写的地图 + 回响碎片 | `world_rumors` 篇章 |

实际内容以服务器的 `config/reveal/reveal.json` 为准。

### 背包持物自动解锁

默认杂项不再需要放入揭秘界面：

| 持有物品 | 自动解锁 |
| --- | --- |
| 指南针 | `misc/compass` |
| 时钟 | `misc/clock` |
| 命名牌 | `misc/name_tag` |

服务器每 20 游戏刻检查一次主背包、快捷栏和副手，正常运行时约为 1 秒。物品不会消耗，也不需要携带或打开辑录册；装备栏、箱子和潜影盒内部不参与检测。

作者可设置 1～2 个物品或标签条件，必须同时满足。若目标只指定篇章，则一次解锁该篇章所有尚未获得、`weight > 0` 的辑录，不按篇章策略逐条抽取；指定 `target_entry` 时只解锁对应一条。

新解锁内容会出现右上角提示、写入研究日志，并按配置发放经验和普通辑录页。一次解锁多条时合并为篇章提示；已经拥有的内容不会反复通知或重复奖励。

## 辑录册右上角按钮

### 揭秘

允许随身揭秘时，不退出辑录册即可进入材料揭秘界面；关闭时按钮不可用，并提示改用研究站。

### 共享

点击“共享”会生成一张共享辑录页，其中包含玩家当前拥有的全部有效辑录。如果背包已满，共享页会掉落在玩家附近。

共享页的提示为“玩家名的 N 条辑录”。其他玩家右键使用后：

1. 只收录自己尚未拥有的有效辑录。
2. 把更新后的进度写入玩家数据和背包中的辑录册。
3. 消耗一张共享页。

共享不会移除导出者自己的进度。

### 日志

研究日志最多保存最近 50 条记录，包括：

- 解锁了哪条辑录；
- 导出了包含多少条辑录的共享页；
- 收录了哪名玩家的共享页，以及新增了多少条辑录。

## 普通辑录页与共享辑录页

两者使用同一个物品 ID：`reveal:story_page`，但保存的数据和用途不同。

- 普通辑录页只对应一条辑录，右键直接阅读，不会把内容加入玩家进度。
- 共享辑录页保存导出者名称与多条进度，右键后写入玩家进度并消耗。
- `give_story_page_on_unlock` 只控制解锁时是否发放普通辑录页。

## 经验与篇章策略

经验奖励按“辑录 → 篇章 → 根配置”的顺序确定。`experience_reward` 为 `-1` 时继续继承，为 `0` 时明确不奖励经验。

| 策略 | 行为 |
| --- | --- |
| `ordered` | 按 `order` 和辑录 ID 依次解锁。 |
| `pool` | 只在当前最小 `order` 的一组辑录中按 `weight` 抽取。 |
| `random` | 在该篇章全部未解锁辑录中按 `weight` 抽取。 |

当解锁方式指定了 `target_entry` 时，不再进行随机或顺序选择，而是直接解锁目标辑录。

## JEI 联动

安装 JEI 后，可以查看当前非隐藏的材料揭秘条件，并使用配方转移按钮把材料移入两个线索槽。JEI 会注明该条件揭秘后是否保留材料。

背包持物、击杀生物、进入群系和完成进度不作为材料配方显示在 JEI 中。它们的条件可在辑录册对应的篇章或条目悬停提示中查看，具体是否显示由作者配置。

## 进度同步

Reveal 同时在玩家数据和辑录册物品中保存进度。打开辑录册或揭秘界面时，会合并：

- 当前玩家的进度；
- 主背包中所有辑录册的进度；
- 副手辑录册的进度。

新解锁或从共享页收录的内容也会写回这些辑录册。箱子、潜影盒和地面掉落物中的辑录册不会自动参与同步，需要先取回背包。

## 旧版揭秘集

`reveal:reveal_codex` 仅为旧存档和旧配方保留：允许随身揭秘时右键进入揭秘界面，不提供目录、日志和共享入口，也不会在首次进入世界时自动发放。
