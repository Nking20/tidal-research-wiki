# 辑录与揭秘

**辑录与揭秘**（Reveal）是一个围绕收集、解锁与阅读条目的模组，提供 NeoForge 1.21.1 和 Forge 1.20.1 两个版本。整合包作者可以用配置定义材料揭秘、背包持有物品、击杀生物、进入群系或完成进度等解锁条件，再用 JSON 编写自己的辑录内容；玩家通过辑录册查看进度、阅读条目并与其他玩家共享记录。

当前版本：`1.3.0`。

## 运行版本

| Minecraft | 加载器 | Java | 内置辑录 |
| --- | --- | --- | --- |
| 1.21.1 | NeoForge 21.1.219 或更新的 21.1.x | 21 | 8 个篇章、123 条 |
| 1.20.1 | Forge 47.2 或更新的 47.x | 17 | 8 个篇章、121 条 |

两个版本分别下载对应的 JAR。多人游戏时，客户端与服务器均需安装对应版本的 Reveal。Forge 版不包含 Creator 唱片与试炼密室两条 1.21 专属辑录，其余核心玩法一致。

## 核心循环

1. 玩家获得并使用 `reveal:index_book`（辑录册）。
2. 在揭秘研究站或随身揭秘界面使用材料，或通过持有物品、击杀、群系和进度条件解锁内容。
3. 材料和事件条件可解锁篇章中的下一条或指定辑录；背包自动解锁还可一次解锁整个篇章。
4. 玩家在辑录册中搜索、筛选和阅读内容，查看未读标记与研究日志。
5. 玩家可以把自己的全部进度导出为共享辑录页，交给其他玩家收录。

线索 A 与线索 B 是并列关系，并非前后步骤。双物品组合不区分摆放顺序；单物品组合可以放在任一槽位，另一个槽位保持为空。

## 模组内容

| 内容 | 注册名 | 用途 |
| --- | --- | --- |
| 辑录册 | `reveal:index_book` | 正常使用查看目录；允许随身揭秘时，潜行使用进入揭秘界面。进度会与玩家记录同步。 |
| 揭秘研究站 | `reveal:research_station` | 放置后右键打开揭秘界面，不需要放入辑录册；关闭随身揭秘后仍可使用。 |
| 辑录页 | `reveal:story_page` | 可作为单条辑录的阅读页，也可保存一名玩家导出的全部共享进度。 |
| 旧版揭秘集（兼容） | `reveal:reveal_codex` | 为旧存档与旧配方保留的兼容物品，不会在首次登录时自动发放；新流程以辑录册为入口。 |

## 默认内容

内置默认内容分为 8 个篇章：

- `vanilla_tips`：原版小提示
- `omitted_note`：被省略的注记
- `unknown_language`：未知语言
- `whisper`：低语
- `creeper_secret`：苦力怕的秘密
- `survival_notes`：生存笔记
- `world_rumors`：世界传闻
- `misc`：杂项，包含指南针、时钟和命名牌三条独立辑录，背包持有对应物品后自动解锁

首次创建 `config/reveal/` 时，模组会把当前资源包中 `data/<命名空间>/re/` 下的条目导出到 `config/reveal/entries/`。之后运行时以该配置目录中的文件为准，可直接编辑，也可在游戏内使用编辑器维护。

## 给整合包作者的入口

| 想做什么 | 推荐入口 |
| --- | --- |
| 调整篇章、解锁条件、随身揭秘、奖励与 UI 风格 | [`config/reveal/reveal.json`](./config) |
| 编写、打包或更新条目文本 | [条目数据与数据包](./datapack) |
| 在游戏内快速维护内容 | `/reveal editor` |
| 检查 ID、物品、标签和分类引用 | `/reveal doctor` |
| 重新读取手动修改的文件 | `/reveal reload` |
