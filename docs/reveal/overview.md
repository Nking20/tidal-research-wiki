# 辑录与揭秘

辑录与揭秘是一个面向 Minecraft NeoForge 1.21.1 的收集与阅读型模组。玩家通过“揭秘集”投入指定物品，解锁不同来源的辑录内容；也可以使用“辑录册”查看已经解锁和还没有解锁的记录。

这个模组适合服务器和整合包作者用于提供原版提示、探索说明、世界传闻、剧情碎片或玩法引导。内容本身走数据包，解锁配方和来源规则走配置文件，方便后期持续扩展。

## 主要内容

- **揭秘集**：放入配置指定的物品或标签物品，解锁对应来源的辑录。
- **辑录册**：查看所有来源的解锁进度，未解锁的辑录会显示为黑影。
- **辑录页**：可单独掉落或给予玩家，右键后直接阅读对应内容。
- **JEI 联动**：在 JEI 中显示揭秘集配方，支持普通物品和物品标签输入。
- **双 UI 风格**：支持 `book_clean` 和 `book_old` 两种书页风格，游戏内可以切换。
- **管理指令**：支持查看进度、全部解析、全部还原、按来源或具体章节调整进度。

## 默认来源

| 来源 | 用途 |
| --- | --- |
| 原版小提示 | 面向新玩家的常规 Minecraft 使用提示 |
| 遗漏笔记 | 探索、基地、物品管理等实用记录 |
| 未知语言 | 偏向附魔、红石、结构和异常现象的说明 |
| 悄悄话 | 较轻量的观察、细节和氛围内容 |
| 苦力怕的秘密 | 使用苦力怕掉落唱片解锁的唱片相关内容 |
| 生存经验 | 生存、跑图、下界、装备和服务器习惯 |
| 世界传闻 | 与旧版本、结构、世界边界、都市传说和存档经历有关的内容 |

## 适合谁使用

- 玩家：通过解锁辑录获得提示、背景说明和探索目标。
- 服务器管理员：用配置控制来源、解锁配方、UI 字号和首次进服物品。
- 整合包作者：用数据包添加自己的章节、图标、顺序和文字内容。
