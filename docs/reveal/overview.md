# 辑录与揭秘

**辑录与揭秘**（Reveal）是一个围绕收集、解锁与阅读条目的 NeoForge 1.21.1 模组。整合包作者可以用配置定义材料、击杀生物、进入群系或完成进度等解锁条件，再用 JSON 编写自己的辑录内容；玩家通过辑录册查看进度、阅读条目并与其他玩家共享记录。

当前发布版本：`1.2.0`。

## 核心循环

1. 玩家获得并使用 `reveal:index_book`（辑录册）。
2. 通过材料揭秘，或完成服务器配置的击杀、群系和进度条件来解锁内容。
3. 解锁目标可以是整个篇章中的下一条辑录，也可以是指定的一条辑录。
4. 玩家在辑录册中查看进度、未读标记、研究日志和正文。
5. 玩家可以把自己的全部进度导出为共享辑录页，交给其他玩家收录。

线索 A 与线索 B 是并列关系，并非前后步骤。双物品组合不区分摆放顺序；单物品组合可以放在任一槽位，另一个槽位保持为空。

## 模组内容

| 内容 | 注册名 | 用途 |
| --- | --- | --- |
| 辑录册 | `reveal:index_book` | 正常使用查看目录；潜行使用进行揭秘。进度会与玩家记录同步。 |
| 辑录页 | `reveal:story_page` | 可作为单条辑录的阅读页，也可保存一名玩家导出的全部共享进度。 |
| 旧版揭秘集（兼容） | `reveal:reveal_codex` | 为旧存档与旧配方保留的兼容物品，不会在首次登录时自动发放；新流程以辑录册为入口。 |

## 1.2.0 默认内容

内置默认内容共有 8 个类别、123 条中文条目：

- `vanilla_tips`：原版小提示
- `omitted_note`：被省略的注记
- `unknown_language`：未知语言
- `whisper`：低语
- `creeper_secret`：苦力怕的秘密
- `survival_notes`：生存笔记
- `world_rumors`：世界传闻
- `misc`：杂项，包含指南针、时钟和命名牌三条独立辑录

首次创建 `config/reveal/` 时，模组会把当前资源包中 `data/<命名空间>/re/` 下的条目导出到 `config/reveal/entries/`。之后运行时以该配置目录中的文件为准，可直接编辑，也可在游戏内使用编辑器维护。

## 给整合包作者的入口

| 想做什么 | 推荐入口 |
| --- | --- |
| 调整类别、线索组合、奖励与 UI 风格 | [`config/reveal/reveal.json`](./config) |
| 编写、打包或更新条目文本 | [条目数据与数据包](./datapack) |
| 在游戏内快速维护内容 | `/reveal editor` |
| 检查 ID、物品、标签和分类引用 | `/reveal doctor` |
| 重新读取手动修改的文件 | `/reveal reload` |

下一步请从[玩家玩法](./gameplay)了解操作流程，或直接查看[配置说明](./config)。
